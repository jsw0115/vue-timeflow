# 보안·웹 취약점·접근성 개발 내재화 안내

본 폴더는 **특정 프로젝트에 종속되지 않는 개발 전·중·후 검토 기준**이다. 공식 법령·계약·기관 내부 점검표가 따로 있다면 그 버전과 적용 범위를 우선 확인한다.

Timebar Diary에는 사용자 제공 ZIP의 개발 참고표로 도입했다. 이번 설치는 공식 원문의 최신성·계약 적합성 검증이나 앱 보안·접근성 인증이 아니다. 프로젝트 사실은 [PROJECT_CONTEXT.md](../PROJECT_CONTEXT.md), 실행 증거는 [적용 기록](../docs/agent/records/2026-11-14-codex-kit/verification.md)을 따른다. 현재 JSP 소스는 확인되지 않았으므로 JSP 전용 검토만 N/A다. Vue의 출력·DOM·권한·접근성 위험은 계속 검토한다.

루트 SECURITY.md에 남아 있는 Artibot 신고처·버전을 이 프로젝트의 신고 정책으로 사용하지 않는다. 이 폴더는 개발 검토 자료이며 별도 신고 창구를 확정하지 않는다.

## 기준 버전 주의
- 2021 개정 SW 개발보안 가이드의 49개 항목, 과거 43개 기준은 같지 않다.
- KGcT의 웹 28개는 제공 기관의 **예시 점검 범위**이며, 모든 프로젝트에 동일한 법정 필수 항목이라 단정하지 않는다.
- 웹 취약점(동작 테스트), SW 보안약점(소스/구현), 접근성(사용성·표준)은 서로 대체할 수 없다.
- N/A는 프로젝트에 해당 기능이 존재하지 않을 때만 증거와 함께 기록한다. 보안 위험을 감추기 위한 일괄 면제는 금지한다.

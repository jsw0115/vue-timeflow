- [ ] 경계(사용자/권한/시스템/파일/외부 API)와 민감 데이터 파악.
- [ ] 예상되는 49개 SW 약점 및 웹 28개 해당 ID를 미리 선택.

## 개발 중
- [ ] 안전한 데이터 바인딩·문맥별 인코딩·서버권한/검증을 적용.
- [ ] 오류·취소·만료·타 사용자 접근의 부정 케이스 테스트 작성.
- [ ] JSP 태그로 인한 경고는 흐름 분석 전 자동 제외하지 않음.
- [ ] 외부 업로드·스캔·실서버 변경 없이 승인된 범위에서 개발.

## PR 또는 완료 직전
- [ ] 변경된 파일 기준 기능·단위/통합/보안 회귀 시험 실행.
- [ ] SAST/SCA/비밀 검사 실행 여부·결과·도구 버전·범위 기록.
- [ ] 웹 동작 시험(28개 중 관련 대상) 및 OWASP Top 10:2025 교차 확인.
- [ ] 웹 UI는 33개 중 관련 항목 자동/키보드/보조기술 점검 구분.

- [ ] 오탐 승인에는 파일·라인·규칙·데이터 흐름·재현 검증·검토자·기한 기록.

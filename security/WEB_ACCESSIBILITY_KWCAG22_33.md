**총 33개.** 검사 결과는 웹 페이지·구성요소·시나리오 단위로 기록한다.

## JSP/HTML 자동·수동 검토 우선순위
- 자동 점검: 중복 id, lang, 이미지 alt, label 관계, heading 구조, 대략적인 색 대비, ARIA 속성 타당성.
- 브라우저 수동: Tab/Shift+Tab, 키보드만으로 모달·파일 업로드·메뉴·달력·오류 정정·로그인 사용.
- 화면낭독기/보조기술: 접근성 이름/상태/변경 알림, 페이지 동적 변경, 검증 오류 위치.
- 색상 대비: 계산만으로 해결됐다고 가정하지 말고 실제 폰트 크기·배경과 상태별 색을 확인한다.
- JSP `<c:forEach>`나 `<c:if>` 태그 자체는 접근성 실패가 아니다. **렌더링된 HTML과 실제 동작**이 기준이다.
- `<label>`/`<button>` 등 HTML 태그를 삭제해 점검을 우회하지 않는다. 구조와 의미를 개선한다.

# safe-debug

문서·명령 경로는 프로젝트 루트 기준이다. 기존 `AGENTS.md`와 `PROJECT_CONTEXT.md`를 함께 따른다.

프런트엔드의 `TEST_GUIDE.md` 명령과 백엔드 Gradle의 관련 `--tests`를 선택한다. `npm test`가 있다고 추정하지 않는다. 사용자 미커밋 변경을 보존한다.


1. 실제 에러/최초 원인·시각·요청 흐름을 확인한다. 추측으로 설정을 바꾸지 않는다.
2. 기여 요인을 확인해 최소 수정과 회귀 시험을 계획한다.
3. 오류 숨김, CSRF/인증 해제, 인증서 검증 비활성화로 문제를 덮지 않는다.
4. 수정·재시험·남은 불확실성 및 보안 영향 보고.

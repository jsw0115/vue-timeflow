# secure-code-review

문서·명령 경로는 프로젝트 루트 기준이다. 기존 `AGENTS.md`와 `PROJECT_CONTEXT.md`를 함께 따른다.

검토 범위는 사용자가 요청한 파일·변경·모듈로 한정한다. Vue 출력·Spring 객체 소유권·Querydsl/JDBC 바인딩을 실제 흐름으로 확인한다. JSP 전용 기준은 해당 소스나 보고서가 있을 때만 적용한다.


1. 실제 코드를 읽고 언어/공격 표면과 변경 범위를 확인한다.
2. `security/SW_SECURE_CODING_49.md`의 49개 항목을 적용/비적용으로 분리한다.
3. 권한·비밀·입력·출력·SQL·XML·파일·SSRF·인증·API 사용의 실제 흐름을 검토한다.
4. 각 발견은 항목 ID, 위험, 파일/라인, 증거, 최소 수정안, 안전한 테스트 방법을 남긴다.
5. 자동분석 경고와 실제 취약을 구분하며 JSP는 예외 정책 참조. 임의 무시 금지.
6. 검사 미실행/미검증을 기록하고 실제 수정 범위만 테스트한다.

코드 설명 시 필수 포함 항목:

비유로 시작: 코드를 일상생활의 사물이나 상황에 비유
다이어그램 작성: ASCII 아트를 활용한 흐름, 구조, 관계 시각화
코드 단계별 설명: 각 단계에서 발생하는 동작을 순서대로 안내
주의 사항 안내: 흔한 실수 및 오해 사례 제시

설명 톤은 대화체로 자연스럽게 유지. 복잡한 개념의 경우 다양한 비유 활용 권장.

## 익명 구매자 의견 원문

> 홈 화면과 잠금화면에서 바로 쓰고 싶어요. 다음 일정, 오늘 할 일 세 개, 기록 시작 버튼 정도만 있어도 자주 쓸 것 같아요. 앱을 열지 않고 완료 처리도 하고요.

## 현재 근거와 분류 이유

웹 홈 위젯은 이미 있지만 휴대전화 OS 위젯과 다르다. Capacitor·Android·iOS 포장 구성이 있으며 OS 위젯 완성은 확인하지 않았다.

## 원하는 결과와 최소 범위

지원 플랫폼 한 곳에서 다음 일정·상위 할 일·빠른 기록 진입 위젯을 제공하고, 직접 완료 액션은 OS 지원 검증 후 확장한다.

## 완료 판단 기준

- [ ] 앱 종료·기기 잠금·로그아웃 후에도 허용 범위만 표시된다.
- [ ] 동일 완료 액션 반복과 오프라인 동작이 중복 저장이나 거짓 성공을 만들지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 23번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

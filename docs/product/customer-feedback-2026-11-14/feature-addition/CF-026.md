## 익명 구매자 의견 원문

> 인터넷이 끊겨도 기록하고 싶어요. 지하철에서도 작성하고, 연결되면 동기화해주세요. 아직 전송되지 않은 기록을 보여주고, 충돌이 나도 어느 한쪽을 조용히 덮어쓰지는 않았으면 해요.

## 현재 근거와 분류 이유

localCollection은 로컬 시연 저장이며 계정별 서버 동기화가 아니다. 서버 FeatureStore에는 version 비교가 있으므로 이를 기반으로 확장할 수 있다.

- [frontend/src/store/localCollection.js](../../../../frontend/src/store/localCollection.js)
- [frontend/src/features/auth/session.js](../../../../frontend/src/features/auth/session.js)
- [backend/src/main/java/kr/timebar/diary/feature/FeatureStore.java](../../../../backend/src/main/java/kr/timebar/diary/feature/FeatureStore.java)

## 원하는 결과와 최소 범위

메모·할 일의 생성과 수정부터 오프라인 대기열을 적용한다. 삭제·첨부·모든 도메인 동기화는 단계적으로 확장한다.

## 완료 판단 기준

- [ ] 응답 유실·중복 전송·순서 뒤바뀜 후 서버에 의도한 변경만 남는다.
- [ ] 두 기기 동시 수정과 계정 전환에서도 초안을 잃거나 다른 계정에 업로드하지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 26번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

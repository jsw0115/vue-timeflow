## 익명 구매자 의견 원문

> 말로 기록하고 싶어요. 이동 중 “방금 운동 40분 했어”라고 말하면 기록 초안이 생겼으면 해요. 잘못 인식한 시간이나 제목은 저장 전에 쉽게 고칠 수 있어야 합니다.

## 현재 근거와 분류 이유

서버 /api/memos/stt는 파일 입력 경계만 있고 유효 요청도 제공자 미연결 503이다. 음성 인식과 문장 해석을 각각 연결해야 한다.

## 원하는 결과와 최소 범위

눌러서 녹음하고 종료하면 전사문·시간·활동 종류의 초안을 보여준다. 확인 전 자동 저장하지 않는다.

## 완료 판단 기준

- [ ] 권한 거부·무음·인식 실패에서 텍스트 입력으로 전환할 수 있다.
- [ ] 40분이 4분으로 인식된 경우 사용자가 수정하고 저장해야 기록이 생성된다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

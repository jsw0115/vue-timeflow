## 익명 구매자 의견 원문

> PC·휴대전화·워치에서 같은 타이머를 이어 쓰고 싶어요. PC에서 시작한 집중을 워치에서 잠깐 멈추고, 휴대전화에서 종료할 수 있으면 좋겠어요. 동시에 두 기기에서 켜도 시간이 중복 집계되지 않고요.

## 현재 근거와 분류 이유

현재 플래너·집중 타이머 상태는 화면 내부에 있다. 워치 화면만 추가해서 해결되지 않으며 계정 공통 세션이 선행되어야 한다.

- [frontend/src/views/focus/FocusView.vue](../../../../frontend/src/views/focus/FocusView.vue)
- [frontend/src/views/planner/PlannerDailyView.vue](../../../../frontend/src/views/planner/PlannerDailyView.vue)
- [backend/src/main/java/kr/timebar/diary/records/RecordsController.java](../../../../backend/src/main/java/kr/timebar/diary/records/RecordsController.java)

## 원하는 결과와 최소 범위

PC와 휴대전화의 한 계정 세션 이어 쓰기를 먼저 완성하고 워치 시작·일시정지·종료를 추가한다.

## 완료 판단 기준

- [ ] 두 기기에서 동시에 시작해도 활성 세션 한 건만 만들어진다.
- [ ] PC 종료 후 늦게 도착한 워치 일시정지 요청이 종료 상태를 되돌리지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 27번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

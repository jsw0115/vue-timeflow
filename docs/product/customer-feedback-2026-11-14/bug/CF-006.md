## 익명 구매자 의견 원문

> ‘자유 타이머’는 정말 자유로웠으면 해요. 현재 구성의 50분 고정 대신 시간을 직접 정하거나 스톱워치처럼 쓰고 싶어요. 중간에 끝낸 13분도 기록할 수 있고요.

## 현재 근거와 분류 이유

FocusView.vue는 포모도로 이외 모드의 목표 시간을 50분으로 고정한다. 완료 시 목표 시간으로 세션을 추가하고 세션은 로컬 ref에 있다. 서버 FOCUS에는 pomodoro·stopwatch·free 허용값이 있다.

- [backend/src/main/java/kr/timebar/diary/records/InsightService.java](../../../../backend/src/main/java/kr/timebar/diary/records/InsightService.java)

## 원하는 결과와 최소 범위

포모도로·사용자 지정 카운트다운·스톱워치를 구분하고 중간 종료 시 실제 경과 시간을 보존한다.

## 완료 판단 기준

- [ ] 13분 수행 후 종료하면 목표 50분이 아닌 실제 13분이 집계된다.
- [ ] 일시정지·재개·새로고침·0초 취소 시 정책대로 저장되고 음수 시간이 생성되지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 6번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

## 익명 구매자 의견 원문

> 루틴에도 예외가 필요해요. 휴가, 아픈 날, 교대근무, 공휴일을 반영하고 싶어요. 하루 쉬었다고 연속 기록이 무너지는 방식은 부담스럽습니다.

## 현재 근거와 분류 이유

recurrence와 루틴 완료 기록이 존재한다. 반복 자체를 새로 만들지 않고 날짜별 예외와 연속 기록 정책을 확장한다.

## 원하는 결과와 최소 범위

날짜별 건너뛰기·기간 일시 중단을 지원하고 연속 기록 계산 정책을 설명한다. 교대근무 주기와 공휴일 자동 처리는 후속 범위다.

## 완료 판단 기준

- [ ] 지정한 휴가 기간에는 알림이 없고 이전·이후 루틴은 유지된다.
- [ ] 완료·건너뛰기·미예정일을 달성률과 연속 기록에서 일관되게 계산한다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

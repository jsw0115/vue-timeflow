## 익명 구매자 의견 원문

> 공유되는 내용을 상대방 시점으로 확인하고 싶어요. 기존 공유 범위 설정에서 한발 더 나아가, 가족·동료별로 실제 무엇이 보이는지 확인하고 싶어요. 회사에는 바쁜 시간만, 가족에게는 일정 제목까지 보여주는 식으로요. AI에 전달하는 기록도 제가 고르고 싶습니다.

## 현재 근거와 분류 이유

공유 가시성·공유 프리뷰·AI 범위 선택이 이미 있다. 현재 공유 프리뷰는 SNS 이미지 성격이므로 수신자 권한 검증 미리보기와 구분한다.

## 원하는 결과와 최소 범위

선택한 수신자가 볼 실제 데이터의 미리보기를 제공하고 바쁜 시간만·제목 포함·상세 포함을 구분한다.

## 완료 판단 기준

- [ ] 바쁜 시간만 허용한 수신자의 API 응답에 제목·본문·첨부 식별자가 포함되지 않는다.
- [ ] 공유 철회와 AI 동의 철회 후 캐시·대기 작업·다운로드 경로에서도 정책이 적용된다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 35번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

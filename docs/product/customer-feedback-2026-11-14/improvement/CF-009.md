## 익명 구매자 의견 원문

> 같은 일을 여러 곳에서 다시 입력하고 싶지 않아요. 할 일을 일정에 배치하고, 집중 시간을 연결하고, 일기에서 돌아볼 때 하나의 기록으로 이어졌으면 합니다. 어디에서 수정해도 일관되게 반영되고요.

## 현재 근거와 분류 이유

## 원하는 결과와 최소 범위

할 일 한 건에서 계획 배치·집중 시작·실제 기록·회고를 오갈 수 있도록 원본 참조를 제공한다.

## 완료 판단 기준

- [ ] 할 일에서 만든 계획과 실제 기록을 각 화면에서 추적하고 한 번만 집계한다.
- [ ] 일정 삭제 후 실제 수행 기록은 유지되며 타인 기록을 임의 연결할 수 없다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 9번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

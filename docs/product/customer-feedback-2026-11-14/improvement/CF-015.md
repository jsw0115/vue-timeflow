## 익명 구매자 의견 원문

> 업무 기록이 보고서까지 이어지면 돈을 낼 이유가 생길 것 같아요. 프로젝트별 실제 시간을 모아 주간 보고서나 인수인계 초안을 만들고 싶어요. 개인 일기와 회사에 공유할 내용은 분리해서요.

## 현재 근거와 분류 이유

업무 리포트·인수인계·문서 내보내기와 REPORT 저장 API가 존재한다. 실제 기록을 근거로 연결하고 공유 전 검토를 강화한다.

- [frontend/src/views/work/WorkReportView.vue](../../../../frontend/src/views/work/WorkReportView.vue)
- [frontend/src/views/work/WorkHistoryView.vue](../../../../frontend/src/views/work/WorkHistoryView.vue)
- [frontend/src/store/docExport.js](../../../../frontend/src/store/docExport.js)
- [backend/src/main/java/kr/timebar/diary/contract/ReportController.java](../../../../backend/src/main/java/kr/timebar/diary/contract/ReportController.java)

## 원하는 결과와 최소 범위

프로젝트와 기간을 고르면 실제 시간·완료 항목·남은 일을 모은 편집 가능한 초안을 만든다.

## 완료 판단 기준

- [ ] 개인 다이어리가 포함된 계정에서도 선택한 업무 기록만 보고서에 들어간다.
- [ ] 초안 수정 후 원본 시간은 바뀌지 않고 공유 파일의 숫자와 화면이 일치한다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 15번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

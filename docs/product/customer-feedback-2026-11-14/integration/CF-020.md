## 익명 구매자 의견 원문

> GitHub·GitLab·Jira 작업과 시간이 연결되면 좋겠어요. 이슈를 선택하고 집중 타이머를 켜면 해당 프로젝트의 작업 시간이 쌓였으면 해요. 커밋 수만으로 생산성을 평가하는 기능은 원하지 않습니다.

## 현재 근거와 분류 이유

업무·WBS·집중 세션은 있지만 외부 이슈를 연결하는 완성된 흐름은 이번 검토에서 확인하지 않았다.

- [frontend/src/views/work/WbsView.vue](../../../../frontend/src/views/work/WbsView.vue)
- [frontend/src/views/focus/FocusView.vue](../../../../frontend/src/views/focus/FocusView.vue)
- [frontend/src/store/workRecords.js](../../../../frontend/src/store/workRecords.js)

## 원하는 결과와 최소 범위

외부 이슈 URL을 업무에 연결하고 해당 업무에서 시작한 시간을 프로젝트별로 합산한다. API 검색은 제공자 한 곳부터 추가한다.

## 완료 판단 기준

- [ ] 같은 이슈에 연결된 여러 집중 세션이 프로젝트 보고서에 중복 없이 집계된다.
- [ ] 비공개 이슈 권한 철회 시 내용을 노출하지 않고 기존 개인 시간은 보존된다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 20번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

## 익명 구매자 의견 원문

> 제가 직접 연동을 만들 수도 있으면 좋겠어요. Zapier·Make·IFTTT 같은 서비스나 웹훅으로 ‘할 일 완료 → 다른 서비스에 기록’ 같은 규칙을 만들고 싶어요. 실행 이력과 중복 실행 방지도 함께요.

## 현재 근거와 분류 이유

자동화 설정 카탈로그는 존재하지만 설정 저장이 외부 이벤트 전달이나 예약 작업 실행을 제공하는 것은 아니다.

## 원하는 결과와 최소 범위

할 일 완료 이벤트의 서명된 외부 웹훅과 선택한 수신 액션 한 종류를 제공한다. 각 서비스의 공식 앱 등록은 별도 후속 단계다.

## 완료 판단 기준

- [ ] 응답 유실로 재전송돼도 수신 측 작업이 한 번만 적용되는 계약을 검증한다.
- [ ] 위조·만료 요청과 내부 주소 대상 발송이 거부되며 영구 실패는 중지된다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 22번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

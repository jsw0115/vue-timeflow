## 익명 구매자 의견 원문

> Notion·Todoist·Microsoft To Do에서 쓰던 일을 가져오고 싶어요. 새 앱을 쓴다고 기존 목록을 다시 만들고 싶지는 않아요. 완료 상태와 마감일이 어떻게 연결되는지 제가 고를 수 있으면 좋겠습니다.

## 현재 근거와 분류 이유

할 일·마감·체크리스트 기반은 있다. 세 서비스의 제공자 어댑터 구현과 권한은 이번 검토에서 확인하지 않았으며 신규 연동 제안이다.

## 원하는 결과와 최소 범위

우선 제공자 한 곳과 목록 하나를 선택해 읽기 전용 가져오기를 제공한다. 검증 후 완료 상태 반영을 추가한다.

## 완료 판단 기준

- [ ] 재가져오기해도 중복 항목이 없고 지원하지 않는 필드는 미리보기에 표시된다.
- [ ] 외부 목록 권한 철회 후 자동 동기화가 중지되고 기존 로컬 항목 처리 방식을 안내한다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 17번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

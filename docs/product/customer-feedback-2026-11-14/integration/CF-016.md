## 익명 구매자 의견 원문

> Google·Apple·Outlook 캘린더 연동을 제대로 쓰고 싶어요. 이미 연동 메뉴가 있으니 실제 연결과 오류 복구까지 완성됐으면 해요. 캘린더별 가져오기·양방향 설정, 중복 방지, 반복 일정 수정도 중요합니다. 네이버 캘린더도 선택지로 있으면 좋겠어요.

## 현재 근거와 분류 이유

캘린더 화면의 연결은 시연이며 IntegrationController가 calendar-sync를 미제공으로 표시한다. 제공자별 실제 연동 권한·범위는 별도 확보가 필요하다.

- [frontend/src/views/sync/SyncStatusView.vue](../../../../frontend/src/views/sync/SyncStatusView.vue)
- [frontend/src/views/settings/SettingsIntegrationsView.vue](../../../../frontend/src/views/settings/SettingsIntegrationsView.vue)
- [backend/src/main/java/kr/timebar/diary/integration/IntegrationController.java](../../../../backend/src/main/java/kr/timebar/diary/integration/IntegrationController.java)

## 원하는 결과와 최소 범위

Google의 선택한 캘린더 가져오기부터 검증하고 양방향·Outlook 순서로 확장한다. Apple·네이버는 연결 방식의 타당성 조사 후 범위를 결정한다.

## 완료 판단 기준

- [ ] 같은 변경을 두 번 받아도 한 건만 반영하고 삭제·반복 일정의 단일 회차 수정이 보존된다.
- [ ] 외부 수정 충돌과 sync cursor 무효화 후 복구해도 로컬의 미전송 변경이 사라지지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 16번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

## 익명 구매자 의견 원문

> 지도와 연결해서 이동 시간까지 계획하고 싶어요. 네이버지도·카카오맵·Google Maps 등의 이동 예상 시간을 일정 앞에 넣고, 출발할 때 알려주면 실생활에서 유용할 것 같아요.

## 현재 근거와 분류 이유

일정의 시간·장소 표현을 출발 계획으로 확장하는 요청이다. 지도별 교통수단·지역·호출료·실시간 교통 지원은 검증하지 않았다.

- [frontend/src/components/PostComposer.vue](../../../../frontend/src/components/PostComposer.vue)
- [frontend/src/views/settings/SettingsNotificationsView.vue](../../../../frontend/src/views/settings/SettingsNotificationsView.vue)

## 원하는 결과와 최소 범위

사용자가 입력한 출발지와 목적지로 지도 앱을 열고 수동 이동 여유 시간을 일정 앞에 배치한다. API 경로 조회는 지원 범위 확인 후 추가한다.

## 완료 판단 기준

- [ ] 예상 이동 시간이 갱신돼도 약속 시작 시각이 바뀌지 않는다.
- [ ] 경로 조회 실패·일정 취소·위치 권한 거부 때 잘못된 출발 알림이 반복되지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 21번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

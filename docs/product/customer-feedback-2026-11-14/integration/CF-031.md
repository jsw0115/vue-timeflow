## 익명 구매자 의견 원문

> 물리 버튼이나 NFC 태그로 기록하고 싶어요. 책상 버튼을 누르면 공부 시작, 운동 공간의 태그를 찍으면 운동 시작처럼요. 기록하려고 휴대전화를 열었다가 다른 앱에 빠지는 일을 줄이고 싶어요.

## 현재 근거와 분류 이유

빠른 기록·타이머에 외부 입력 장치를 연결하는 요청이다. NFC와 물리 버튼의 전송 방식·기기 지원은 서로 다르다.

- [frontend/src/views/planner/PlannerDailyView.vue](../../../../frontend/src/views/planner/PlannerDailyView.vue)
- [frontend/capacitor.config.ts](../../../../frontend/capacitor.config.ts)
- [frontend/src/store/automations.js](../../../../frontend/src/store/automations.js)

## 원하는 결과와 최소 범위

등록한 NFC 태그를 읽어 지정 활동의 시작 초안을 열고, 지원 허브의 버튼 이벤트 한 종류를 추가한다.

## 완료 판단 기준

- [ ] 같은 태그 연속 스캔·버튼 튕김으로 세션이 여러 개 생성되지 않는다.
- [ ] 복사된 태그를 다른 계정으로 읽어도 원래 사용자의 기록을 변경하지 못한다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 31번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

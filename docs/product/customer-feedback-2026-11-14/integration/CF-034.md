## 익명 구매자 의견 원문

> 기상·취침 루틴과 연결하고 싶어요. 제가 정한 취침 루틴을 시작하면 조명을 낮추고 하루 회고를 제안하는 식이면 좋겠습니다. 자동화마다 실행 조건을 확인하고, 한 번에 중지할 수 있어야 해요.

## 현재 근거와 분류 이유

루틴·회고·자동화 설정을 여러 단계의 외부 실행으로 연결하는 요청이다. 기상 자동 감지를 전제하지 않는다.

- [frontend/src/views/routines/RoutineListView.vue](../../../../frontend/src/views/routines/RoutineListView.vue)
- [frontend/src/store/automations.js](../../../../frontend/src/store/automations.js)
- [frontend/src/store/plannerReviews.js](../../../../frontend/src/store/plannerReviews.js)

## 원하는 결과와 최소 범위

사용자가 누르는 취침 루틴 한 개를 조명 변경과 회고 열기 두 동작에 연결한다. 시간 예약은 이후 추가한다.

## 완료 판단 기준

- [ ] 같은 루틴을 연속 실행하거나 예약 이벤트가 중복돼도 회고·조명 명령이 중복 생성되지 않는다.
- [ ] 조명 실패 시 회고를 잃지 않고 전체 중지 후 새 외부 명령이 발송되지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 34번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

## 익명 구매자 의견 원문

> Slack·Teams 메시지를 할 일로 연결하고 싶어요. 부탁받은 메시지를 선택하면 원문 링크와 함께 할 일 후보가 생기고, 담당자와 마감일을 확인해서 저장하는 방식이 편할 것 같아요.

## 현재 근거와 분류 이유

프로젝트에는 자체 채팅과 할 일이 있지만 외부 Slack·Teams의 메시지 선택·권한 모델은 별도다. 대화 전체 수집을 전제로 하지 않는다.

- [frontend/src/components/PostComposer.vue](../../../../frontend/src/components/PostComposer.vue)
- [frontend/src/features/chat/views/ChatWorkspace.vue](../../../../frontend/src/features/chat/views/ChatWorkspace.vue)
- [docs/api/task-planner-contract.md](../../../../docs/api/task-planner-contract.md)

## 원하는 결과와 최소 범위

사용자가 선택한 메시지 한 건을 초안으로 전달하고 내용·담당자·마감 확인 후 저장한다.

## 완료 판단 기준

- [ ] 사용자가 선택하지 않은 주변 메시지가 저장되거나 모델로 전송되지 않는다.
- [ ] 같은 메시지를 다시 가져오면 기존 후보를 안내하고 담당자가 임의로 자동 지정되지 않는다.
- [ ] 실제 변경·검증 명령·결과·남은 제한을 아래 이력에 남기고 상태를 변경한다.

## 관리 이력

- 2026-11-14. 원문 18번을 등록하고 현재 근거·최소 범위·검증 기준을 제안했다. 제품 구현과 기능 승인은 아직 수행하지 않았다.

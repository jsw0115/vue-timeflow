# 화면·작성 흐름 개선 (2026-09-25)

## 적용 범위

이번 변경은 Vue 프론트엔드의 로컬 시연 기능입니다. 기존 Spring Boot API·MariaDB 스키마는 변경하지 않았습니다.
로컬 저장은 로그인 사용자별 서버 저장이 아니며, 기기·브라우저·접속 주소가 달라지면 공유되지 않습니다.

| 요청 | 적용 내용 | 확인 위치 |
| --- | --- | --- |
| LNB 하루 모드 | 드롭다운 열기/닫기, J/P/밸런스 선택, 기존 모드 설정·홈 구성 연동 | 좌측 상단 |

## 업무 기록 상세 설계

근무·휴가 기록은 WBS 작업의 공수에 합산하지 않습니다.

| 유형 | 추가 상세 항목 | 주요 검증 |
| --- | --- | --- |
| 공통 | 제목, 담당자, 연결 작업, 기간, 상태, 상세 사유, 태그·멘션 | 제목/담당 필수, 종료 > 시작 |
| 연차 | 실제 사용할 연차 일수 | 0.5일 단위, 0.5~365일; 공휴일 자동 산정 없음 |
| 반차 | 오전/오후, 시간 | 동일 날짜, 사용 일수 0.5일 |
| 외근 | 방문 장소, 방문처/담당자 | 장소 필수 |
| 출장 | 장소, 방문처, 교통/숙박, 예상 경비 | 장소 필수, 경비 0~100,000,000원 |
| 이직 | 이전/이직 회사, 직무·직급, 인수인계/준비 사항 | 이직 회사와 직무 필수 |

유형 변경 후 저장하면 이전 유형의 전용 상세값은 정리합니다.
상태의 '승인'은 개인 메모이며 실제 회사 결재, 근태 처리, 연차 차감 기능이 아닙니다.

## 로컬 실행

PowerShell에서:

```powershell
cd E:\vscode-proj\vue-timeflow-proj\frontend
npm run dev:devices
```

PC와 모바일 프리뷰를 함께 엽니다. 하나씩 확인하려면 실행 중인 서버를 종료한 뒤 아래 중 하나를 사용합니다.

```powershell
npm run dev:web
npm run dev:mobile
```

여러 명령을 동시에 실행하면 기본 포트 5173이 충돌할 수 있습니다.
기존 서버를 재사용할 때는 http://localhost:5173/__preview 로 접근합니다.
localStorage는 origin(호스트·포트)별이므로 localhost와 127.0.0.1의 시연 데이터도 분리됩니다.
실기기·네이티브 테스트는 [로컬 플랫폼 가이드](../development/local-platforms.md)를 참고하세요.

## 모듈 구조

- `components/Modal.vue`: native dialog 기반 모달, Escape 닫기, 포커스 복원.
- `components/PostComposer.vue`: 4개 종류의 통합 작성 탭과 제출.
- `components/EventDateFields.vue`: 공통 시작/종료 일시 입력.
- `components/TagMentionInput.vue`: 태그·멘션 추천 및 키보드 입력.
- `components/WorkRecords.vue`: 업무 기록 유형별 폼.
- `components/CommunityCreateModal.vue`: 공통 커뮤니티 생성 모달.
- `store/appState.js`, `writing.js`, `communities.js`: 화면 간 공유 데이터.
- `store/localCollection.js`: 시연 데이터 복원·저장 및 저장 실패 안내.
- `store/postIndex.js`, `tagging.js`: 원본 글을 종류/ID로 식별해 태그 인덱스 수정·삭제 동기화.
- `utils/postValidation.mjs`: 일정·루틴·챌린지·업무 기록 입력 검증.
- `interaction.css`: 기본 스타일 이후 적용하는 모달·포틀릿·모바일 보정.
- `tests/writing-flows.test.mjs`: 입력·저장·인덱스·렌더링·HTML 안전 출력 회귀 테스트.

## 저장과 보안 경계

- 주요 데이터는 `timeflow.demo.v1.*` 키의 localStorage에 저장합니다. 기존 모드/위젯 설정 키는 유지합니다.
- 개인·업무 데이터의 암호화나 계정별 접근 제어를 제공하는 저장소가 아닙니다. 실제 민감정보는 입력하지 마세요.
- 서버 알림, 상대방 멘션 알림, 채팅 전송, 초대, 커뮤니티 접근 권한, 가입 승인 처리는 아직 연동되지 않았습니다.
- 채팅은 현재 탭의 시연 대화이고, 다이어리 첨부 사진은 미리보기 전용입니다.
- 입력 본문은 HTML로 실행하지 않습니다. 태그·멘션은 텍스트 조각으로 렌더링하며 주소록의 비차단 사용자만 추천합니다.
- UI 입력 검증은 서버 권한 검증을 대신하지 않습니다. API 연결 시 소유자/커뮤니티 멤버십 확인 및 동일한 기간·숫자 검증을 서버에서 수행해야 합니다.
- 일부 홈 통계/D-Day는 기존 예시 데이터이며 화면에 '시연용 예시 데이터'로 표시합니다.
- 저장소 오류·용량 초과 시 경고를 표시합니다. 경고가 나온 상태에서는 새로고침 후 유지된다고 보장할 수 없습니다.

## 3단계 점검 결과

1. 구조·빌드: 전체 Vue 프로덕션 빌드 성공(183개 모듈). 공통 폼과 스타일 적용 순서를 점검했습니다.
2. 기능 회귀: `npm run check:writing` 10/10 통과. 잘못된 날짜·시간/숫자, 미가입 커뮤니티, 저장 복원, 글 인덱스 수정·삭제, 13개 주요 컴포넌트 서버 렌더, 빈 홈, WBS 유형별 검증을 확인했습니다.
3. 보안·기존 기능: HTML 입력 비실행 및 차단된 멘션 제외 테스트 통과. `npm run check:preview` 3/3 통과(허용 경로, 프록시, 배포 번들 분리). `npm audit --audit-level=high` 알려진 취약점 0건.

남은 경고: JS 단일 번들 약 648 kB로 500 kB 청크 경고가 있습니다. 빌드 실패는 아니며 라우트 지연 로딩은 별도 최적화 과제입니다.

중요: 연결된 브라우저가 없어 실제 클릭·스크린샷·레이아웃·키보드 포커스 검증은 수행하지 못했습니다.
서버 렌더 테스트는 실제 DOM 이벤트나 시각 검증을 대체하지 않습니다. iOS/Android/Electron 실행 검증도 이번 변경에 포함되지 않았습니다.

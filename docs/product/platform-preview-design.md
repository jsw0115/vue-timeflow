# 플랫폼 화면 및 로컬 미리보기 설계

2026-09-25. 공통 Vue 라우트·도메인, 화면 폭에 따른 반응형 UI를 사용한다.

| 구분 | 레이아웃 목표 | 이번 반영 / 제한 |
|---|---|---|
| PC browser | 기존 사이드바244px, 내용 최대1180px | 1440×900 비교 프레임 제공 |
| Mobile web | 760px 미만 메뉴 off-canvas, 내용 전체폭 | 320/360/390/430 비교, viewport meta 반영 |
| Tablet | 가로/세로 확인 | 768px 비교 옵션 |
| Android / iOS | 같은 Vue dist를 Capacitor로 감쌈 | 기존 sync/open 명령 문서화, 네이티브 빌드는 별도 |
| Electron PC | 기존 desktop:dev | 기존 실행 방법 문서화, 설치파일 검증 별도 |

## 화면 흐름

/__preview에서 화면·보기·너비 선택 → 같은 앱 경로를 PC/모바일 iframe으로 로딩 → 각각 실제 UI를 조작 → 필요하면 새로고침.
별도 열기는 선택한 앱 경로만 새 창으로 연다. 외부 주소·/api·관리자·미리보기 자기 자신은 선택지에서 제외한다.
쿼리의 잘못된 값은 기본값으로 복원한다. 데이터 변경은 각 앱의 기존 행동을 따르며 미리보기 도구는 API 토큰을 생성하거나 인증을 우회하지 않는다.

## 운영 경계

Vite serve 전용 plugin이 /__preview를 제공한다. HTML/JS/CSS는 public 폴더 밖 dev-preview에 두어 운영 dist에 복사되지 않게 한다.
운영 SPA fallback 때문에 /__preview에 앱 index가 응답할 수는 있지만 미리보기 도구가 배포되는 것은 아니다.
LAN 연결은 dev:lan을 실행했을 때만 허용한다. 기본 서버 host는127.0.0.1.
PC와 mobile의 origin은 같아 localStorage 공유; 기기별 격리나 실제 동기화로 오해하지 않도록 화면에 안내한다.

## 접근성과 확인 기준

컨트롤에 label, iframe에 title, 키보드 focus ring, 44px 컨트롤, lang=ko와 viewport를 제공한다.
축소 모션을 기본 사용하지 않고 reduced-motion 설정을 존중한다.
비교 화면 색상은 DESIGN.md의 #000/#fff/#f5f3f1/#e5e5e5/#2f5d46을 사용한다.
기존 앱 전체가 320px에 최적화된 것은 아니다. 테이블/타임테이블의 가로 스크롤, 모바일에서 숨기는 요약 위젯은 후속 디자인 검토 대상으로 남는다.

## 통합 일정 탭 후속 화면 설계

상단에 전체/일정/할 일/루틴 복수 선택, 날짜 범위, 카테고리, 상태, 검색을 배치한다.
모바일은 유형 칩을 스크롤 가능하게 하고 나머지 필터는 바텀시트, PC는 상단 도구막대.
필터는 URL에 보존하고 필터 변경 시 cursor를 초기화한다.
빈 결과에는 필터 초기화 버튼, 오류에는 재시도, 통신 끊김에는 마지막 동기화 시각을 보여준다.
TASK 상태 변경은 목표 상태 PUT, 루틴은 날짜별 PUT, 일정은 상세 편집으로 이동한다.
이 통합 필터 UI의 신규 API 연결은 설계 대상이며 이번 로컬 미리보기 구현과 구분한다.

## 릴리스 순서

1. 인증/소유권/영속화, 현재 공용 메모리 플래너 제거, 현재 stub을 실제 도메인 서비스로 구현.
2. P0 API 및 웹 실제 API 클라이언트 연결, 문서와 DTO 계약 테스트.
3. P1 동기화·충돌·공유 검증 후 네이티브 기기에 적용.
4. 동의·쿼터·비용 관리가 있는 상태에서 P2 도입.

현재 프런트엔드 로그인은 화면 이동이며 서버 인증과 연결되어 있지 않다. 화면 시연의 성공을 로그인·DB 저장 성공으로 보지 않는다.

# 설계 의사결정 맥락

## 2026년 10월 31일

- 사용자는 취업과 연구 분야 트렌드를 분석하고 작성 방향 및 시장 분석을 실행으로 연결하는 유료 기능의 상세 설계를 요청했습니다. 별도 AI 서버 구성도 가능합니다.
- 한국 사용자와 한국어 앱을 기본 대상으로 하며 글로벌 자료를 한국의 실제 채용 수요와 동일시하지 않습니다.
- 이번 요청은 새 기능의 분석과 설계입니다. 기존 503 AI 및 결제 경계를 실제 제공자와 연결하거나 앱 기능을 변경하는 작업으로 해석하지 않습니다.
- 근거는 관측된 사실, 기관의 전망, 제품팀의 가설로 나눕니다. 미래 직업의 성장과 개별 사용자의 취업 가능성을 수치 하나로 단정하지 않습니다.
- 현재 프런트엔드의 다수 store는 로컬 시연 저장소입니다. 유료 개인화의 선행 조건에 계정별 서버 저장과 명시적 데이터 선택을 포함합니다.
- 기존 매뉴얼 및 실행 검증 작업은 별도 담당자가 마무리하고, 새 제품 설계 폴더와 편집 범위를 분리합니다.

## 조사와 설계 검토 결과

- 공개 고용 자료의 국가·발행일·관찰 또는 전망 기간을 분리했습니다. AI 노출도를 개인 실업 확률로 사용하지 않고, 새 역량과 새 직업을 같은 뜻으로 취급하지 않습니다.
- 초기 대상은 기존 경험을 가진 소프트웨어·데이터 분야 전환자로 제안했습니다. 이는 현재 기능과의 연결을 검증하기 위한 가설이며 해당 분야 채용의 용이성을 주장하는 선택이 아닙니다. 연구는 별도 소규모 파일럿으로 평가합니다.
- 기존 AI 보고서·구독 UI의 시연 상태와 실제 제공자 미연결 503을 소스에서 확인했습니다. 유료화보다 계정별 서버 저장·자료 선택·동의·작업 복구가 선행합니다.
- 출처가 있는 분석, 사용자가 확인한 경험·문헌, 수정안 비교, 승인한 행동과 실제 결과의 연결을 제품의 중심으로 정했습니다. 개인 자료 전체 자동 업로드와 자동 외부 발송은 범위에 포함하지 않습니다.
- 무료 기록·문서 이력 조회·복원과, 비용이 드는 새 AI 분석·수정안 생성을 구분했습니다. 월 9,900원·14,900원과 공헌이익 예시는 실험 가설입니다.
- Elicit의 2026년 9월 Routines 발표를 반영해 경쟁사의 정기 갱신 기능을 인정했습니다. 차별화는 자신의 실험·집필·실행 결과와의 연결에서 검증합니다.
- 읽기 전용 동료 검토에서 제기된 실험 집단별 분모, 자동 재분석 사전 한도 동의, 무료 버전 관리 범위, 가격과 작업당 원가의 연결을 보완했습니다.
- 기술 검토에서 제기된 외부 호출 직전 동의 검사, 동시 예산 예약, 임대 만료 시 외부 비용 중복, webhook·작업자 별도 인증 경계를 설계에 반영했습니다.
- 웹 우선으로 기존 Vue를 활용하고, Capacitor·Electron은 같은 서버 작업과 결과를 공유하도록 제안했습니다. 네이티브 설치·스토어 결제는 실제 플랫폼 검증이 필요한 후속 범위입니다.
- 새로운 기능 코드는 변경하지 않았습니다. 앞선 매뉴얼은 별도 커밋 a076a6a와 3d042f9로 정리되었으며, 해당 실행 검증 증거를 새 제품의 구현 완료 증거로 사용하지 않습니다.

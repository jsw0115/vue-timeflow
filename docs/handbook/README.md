## Word에서 갱신하기

각 파일에 `CREATEDATE`, `SAVEDATE`, `TOC` 필드를 넣었습니다. 장 제목은 Word의 제목 1 또는 제목 2 스타일로 작성하세요.

1. 데스크톱 Word에서 편집하고 먼저 저장합니다.
2. **Ctrl+A → F9 → 목차 전체 업데이트**를 선택합니다. 노트북은 Fn+F9가 필요할 수 있습니다.
3. 날짜와 목차를 확인하고 다시 저장합니다. 바닥글 필드는 필요하면 바닥글에서 따로 갱신합니다.

생성일은 최초 생성일을 유지하고 수정일은 마지막 저장 시각을 표시합니다. 오늘 날짜로 바뀌는 필드가 아닙니다. 미리보기나 일부 웹 편집기는 필드를 계산하지 않을 수 있습니다. 매크로는 사용하지 않습니다.

## 원문에서 재생성하기

`source/`의 한국어 원문과 [`build_handbook.py`](../../scripts/docs/build_handbook.py)를 함께 관리합니다. Python 3.10 이상과 `python-docx`가 있는 환경에서 프로젝트 루트 기준으로 실행합니다.

```powershell
python scripts/docs/build_handbook.py
python scripts/docs/verify_handbook.py
```

재생성은 Word에서 직접 편집한 내용을 덮어씁니다. 먼저 원문에 반영하고 변경을 보관하세요. 생성 후 Word 또는 필드 계산이 가능한 편집기에서 목차 전체를 갱신하고 페이지 배치까지 확인해야 합니다. 검증기는 필드와 문서 구조를 확인하며 화면 조판을 대신하지 않습니다.

실제 제작과 검증 결과는 [작업 기록](../development/documentation-2026-10-31/verification.md)에 남깁니다.

# 작업 계획

- 요청(2026-11-18): 320px 가로 넘침 문제의 원인을 찾아 고친다.
- 현재 확인한 사실
  - 앞 작업에서 "320~360px에서 앱 셸 전체가 넘친다"고 보고했는데, 헤드리스 Chrome `--window-size` 캡처로 판단한 것이었다.
  - 헤드리스 Chrome 창은 320·360을 줘도 실제 뷰포트가 526px이다. 그 캡처는 넓은 화면을 잘라 본 것이라 판단 근거가 될 수 없다.
- 범위: 정확한 폭(iframe)으로 모든 정적 화면·환경설정 섹션(95개)을 재고, 실제 넘침의 원인을 고친다. 320px 외에 375·768·1024px도 같이 잰다.
- 성공 기준: 320·360·375·414·768·1024px에서 95개 화면 넘침 0, 프런트 전체 테스트·빌드 통과, 재발 방지 정적 검사.
- 보안: 해당 없음(CSS·마크업 스타일·개발 점검 페이지). 점검 페이지는 빌드 결과에 포함되지 않는다.
- 접근성: DESIGN.md 8장 320px·200% 확대 재배치 기준.
- 허용된 작업: 코드·문서 수정과 로컬 커밋.

# 작업 계획

- 요청: 2026-11-26 점검에서 확인하지 못한 항목을 이어서 브라우저로 점검한다.
- 현재 확인한 사실: [2026-11-26 점검](../../../quality/browser-test-2026-11-26.md)의 "확인하지 못한 것"은 실제 백엔드, 768·1024px, 200% 확대, 다크·세피아·고대비와 나머지 색상 테마, 키보드 전체 흐름, 화면 읽기 프로그램이다. 컨테이너에 Docker·JDK가 있어 격리 DB와 백엔드를 띄울 수 있었다.
- 범위/제외: 점검과 기록만 한다. 찾은 문제는 원장에 등록하고 코드는 고치지 않는다. 화면 읽기 프로그램·실기기는 이 환경에 없어 제외한다. 운영 DB는 쓰지 않는다.
- 성공 기준: 각 항목의 실행 결과와 근거를 결과서·원장·07 RUN에 남긴다. 실행하지 못한 항목은 NOT_RUN으로 적는다.
- 보안 관련 ID/검증: 해당 없음(코드 변경 없음). 점검용 계정과 격리 DB만 썼다.
- 접근성 대상/검증: 대비, 초점 표시, 대화 상자 초점, 반복 영역 건너뛰기(6.4.1). 자동 점검과 키보드 조작이며 정식 KWCAG 점검은 아니다.
- 사용자 요청으로 이미 허용된 작업과 추가 확인이 필요한 작업: 점검·문서화·작업 브랜치 푸시는 허용됨. 찾은 문제를 고치는 일은 사용자 요청이 필요하다.

# 결정·근거·인수인계 메모

- 선택한 대안/이유: 앱 셸 밖 화면은 각 화면을 고치지 않고 `App.vue`에서 한 번 감쌌다. `main.bare-main`은 전역 `main` 규칙을 되돌리고, 자식 최대 너비 규칙(`main:not(.chat-shell)>*`)에서도 뺐다. 안내 화면 h1은 `h1.heading-title-lg/md`로 예전 h2·h3 크기를 유지했다. 터치 영역은 레이아웃이 바뀌지 않도록 `position:relative`와 투명한 `::after`만 썼다. 창 닫기는 각 창 컴포넌트가 열 때의 입력을 기억했다가 경로가 바뀔 때 비교한다.
- 넓히지 않은 곳: 검색칸 안 지우기 버튼(넓히면 입력칸을 덮어 누르면 검색어가 지워진다), 캔버스 열 이동 버튼(마우스를 올려야 보여 터치에서 보이지 않는 버튼이 눌린다), 할 일·루틴 줄 체크(label을 넓히면 줄을 눌러 상세를 여는 동작이 완료 표시로 바뀐다), 공수 계산 숫자 칸(보이는 칸이 18px). IMP-026으로 남겼다.
- 화면 비교에서 찾은 것: (1) `bare-main`의 자식이 본문 최대 너비에 묶여 1440px 로그인 화면이 좁아졌다. (2) 채팅 제목 선택자를 `.chat-title`로 바꾸자 같은 규칙을 쓰던 멘션함·태그함 제목이 바뀌었다. 둘 다 고쳐 다시 비교했다.
- 다음 작업·미확인: IMP-026 결정. PR-06은 사용자 PC 확인 대기.

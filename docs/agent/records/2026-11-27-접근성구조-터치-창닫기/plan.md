# 작업 계획

- 요청: 사용자가 정한 IMP-023(셋 다 고친다)·IMP-024(작은 버튼부터 누르는 영역만 44px)·IMP-025(비어 있으면 닫고 쓰던 게 있으면 둔다)를 고치고 시험·빌드·브라우저 확인 후 커밋·푸시한다.
- 현재 확인한 사실: 앱 셸 밖 화면은 `App.vue`의 `<router-view v-if="isBare">`로 그려져 `main`이 없다. 전역 `main`은 여백·100vh·안쪽 스크롤·자식 최대 너비가 있다. 채팅 창 제목과 멘션함·태그함 제목이 같은 `.chat-page-head h1` 규칙을 쓴다. 새 글 작성의 쓰던 내용은 컴포넌트 안에만 있어 닫으면 사라진다.
- 범위/제외: 보이는 모양은 바꾸지 않는다. 터치 영역은 투명한 의사 요소로만 넓히고, 동작이 바뀌는 곳(줄을 누르면 상세가 열리는 할 일 줄)과 보이는 크기를 바꿔야 하는 곳은 IMP-026으로 남긴다.
- 성공 기준: 106개 경로에서 main·h1 문제 0, 넓힌 영역 100% 반응, 수정 전후 화면이 같음, 빈 창만 뒤로 가기에 닫힘. 시험·빌드 통과.
- 보안 관련 ID/검증: 해당 없음.
- 접근성 대상/검증: 랜드마크·제목 구조, 터치 대상 크기. 정식 점검 아님.
- 사용자 요청으로 이미 허용된 작업과 추가 확인이 필요한 작업: 수정·커밋·작업 브랜치 푸시 허용. IMP-026은 결정 필요.

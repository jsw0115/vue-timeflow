- 감사 결과(1440·390px 캡처): 카드 안쪽 12px·카드 사이 12px, 목록 두 종류의 행 높이 40/32px, 바로가기 글자와 태그의 오른쪽 끝 불일치, 한국어에 모노 서체(`5개 중 4개 입력`), `학력을(를)` 조사, 늘 보이는 권한 안내 문장, 같은 이름 바로가기 2쌍, 모든 행의 pill 태그, 단계 비율을 6줄 숫자 목록으로 표시, 같은 크기 카드 2×2.

- 범위/제외: 대시보드 화면, `careerModel.mjs`의 순수 헬퍼, 관련 테스트. 라우터 부제(`목표와 다음 마감, 최근 활동을 한눈에`)·전역 토큰 이름·다른 화면은 바꾸지 않는다.
- 성공 기준: 모든 간격 4px 격자·DESIGN 카드 여백 24px, 행 높이 통일, 모노는 날짜·숫자에만, 영역 순서(목표별) 유지, 로딩·오류·빈 상태 유지(오류 상태 보강), 320~1440px 가로 넘침 없음, 기존 테스트 통과.
- 보안 관련 ID/검증: 입력·인증·권한·쿼리 변경 없음. 표시 문자열은 Vue 보간만 사용(v-html 없음).

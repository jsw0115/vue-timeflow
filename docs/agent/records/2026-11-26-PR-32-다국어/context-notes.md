# 결정·근거·인수인계 메모

- 현재 확인된 구현/설정: 한국어 원문을 사전 키로 쓴다(DESIGN.md: 한국어가 1차 기준). `translate()`는 문자열이 아닌 값을 그대로 보이고, 자리표시 값을 넘긴 때만 `{…}`를 채운다. 숫자 뒤 단위는 이름표와 글자가 같아도 뜻이 달라 사전과 따로 둔다(`unit(ko, n)`·`UNITS_EN`·`UNITS_EN_ONE`, `unitWord()`·`UNIT_WORDS_EN`). 표시 함수(`formatMinutes`·`figureSummary`·`dayLabel` 등)는 번역 함수를 인자로 받고 기본값은 한국어(`korean`)다. 저장값은 `<option value="한국어">`로 두고 보이는 글자만 옮긴다.
- 선택한 대안/이유: 09 Q-38 (1)~(5) 사용자 결정을 따른다. 커리어 화면부터 옮기고, English 선택은 계속 보이며, 문서 버전에 언어를 표시하고(원문을 덮어쓰지 않음), 용어는 코드 사전과 시험·dev-docs 12로 관리하고, 우선 영어만 둔다. design 12 DEC-12에 승인 기록이 있다.

## 3b 계획(2026-11-20)

- 요청: "PR-10 남은 단계 이어서 진행해줘." 사용자 결정 Q-25(커뮤니티 회원과 채팅방 자동 동기화), Q-26(챌린지별 인증 랭킹, 그 시간에 했는지 확인하는 실제 기록 연계, 기록 공개에 동의하는 별도 챌린지).
- 소스 대조: 챌린지 API(목록·만들기·참여·인증·랭킹)는 있지만 목록에 내 참여·인원·내 인증 수가 없고, 참여 취소가 없고, 랭킹에 이름이 없다. 커뮤니티 채팅 서버는 없고 채팅 모듈(`/api/chat`, MySQL·Redis, `app.chat.enabled`)은 커뮤니티 회원과 따로 관리된다.
- 실제 기록 근거: `ActualRecordingService.start`가 `startedAt`을 서버 시각으로 찍고, 종료는 현재 시각을 넘을 수 없다. 백업 복원으로 들어온 기록은 `finishKey`가 없어 구분된다. 인증 근거는 `finishKey`가 있는 완료 기록만 쓴다.
- 단계: 3b-1 챌린지 서버 → 3b-2 챌린지·랭킹 화면과 검색 색인 → 3b-3 커뮤니티 채팅 서버·화면. 단계마다 검증·문서·커밋.
- 보안: 기록 공개 챌린지만 기록 제목·시각을 다른 회원에게 보인다. 동의 없이는 참여할 수 없고, 참여를 취소하면 인증과 근거를 지워 바로 보이지 않는다. 일반 챌린지는 인증 방식(직접·기록 확인)만 보인다. 탈퇴·강퇴한 회원은 랭킹·인증 내역에서 빠진다. 커뮤니티 채팅방 접근은 매 요청 커뮤니티 활성 회원인지로 판단한다.

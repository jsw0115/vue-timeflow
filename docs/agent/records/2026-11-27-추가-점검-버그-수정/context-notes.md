# 결정·근거·인수인계 메모

- 현재 확인된 구현/설정: 전역 링크 색은 `a:not([class])`뿐이다. `class=""`인 링크 중 상당수(플래너 보기 탭, 멘션함·태그함 탭, 원문·대화 열기, 태그 칩)는 부모 규칙에서 색을 받는다.
- 선택한 대안/이유: 처음에 전역 규칙을 `class=""`·활성 클래스로 넓혔다가, 106개 경로 링크 색 비교에서 위 링크들까지 accent로 바뀌는 것을 보고 되돌렸다. 대신 문장 속 RouterLink 9곳에 기존 `.inline-link`를 붙였다. 본문 바로가기는 해시 라우터(GitLab Pages)를 깨지 않도록 `@click.prevent`로 초점만 옮긴다. 관리자 버튼은 `checkAdminRole`(adminClient.mjs)과 `refreshAdminButton`(admin.js)으로 계정당 한 번 확인한다. 실패하면 버튼을 숨긴다.
- 오탐/예외와 근거·승인 상태: 이름 없는 버튼 9건은 글양식 스위치(`<label>`로 이름) 오탐으로 이전과 같다. 409 1건은 충돌 확인용으로 일부러 만든 것이다.
- 다음 작업·미확인: 화면 읽기 프로그램·실기기·Pretendard 글꼴은 확인하지 못했다. 관리자 버튼은 역할 확인이 네트워크 오류로 실패하면 같은 계정으로는 새로고침 전까지 다시 묻지 않는다.
- 마지막 실행 명령·종료 코드·증거 경로: `frontend`에서 전체 시험 종료 0(397개), `npm run build:web` 종료 0. 브라우저 증거는 dev-docs 07 RUN-292. 점검 스크립트는 저장소 밖 세션 임시 폴더에 있다.

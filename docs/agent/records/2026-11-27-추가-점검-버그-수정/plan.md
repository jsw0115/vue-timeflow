# 작업 계획

- 요청: 2026-11-27 추가 점검에서 찾은 버그(BUG-012~BUG-014)를 고치고, 사용자가 정한 개선(IMP-019~IMP-022)을 반영한다. 시험·빌드·브라우저 확인 후 문서에 반영하고 커밋·푸시한다.
- 현재 확인한 사실: [추가 점검 결과](../../../quality/browser-test-2026-11-27.md). 메모 저장소(`createFeatureStore`)에 `update`·`remove`가 있고 서버에 메모 수정·삭제 경로가 있다. `/api/auth/me`는 DB에서 읽은 역할을 돌려준다. 로그인·가입 화면은 서버 message를 `tr()`로 넘긴다.
- 사용자 결정: IMP-019 수정·삭제 둘 다, IMP-020 지금 방식 유지·문서 수정, IMP-021 `/api/auth/me` 역할 사용, IMP-022 문장 지우기.
- 범위/제외: 서버 코드와 API는 바꾸지 않는다. 서버 오류 문구의 한국어 문체는 바꾸지 않는다.
- 성공 기준: 기본 파랑 링크 0, 다크 대비 부족 0, 첫 Tab에 본문 바로가기, 영어 화면 서버 오류 영어, 일반 계정이 `/api/admin/stats`를 부르지 않음, 메모 수정·충돌·삭제가 실제 백엔드에서 동작, LMS 문장 없음. 시험·빌드 통과.
- 보안 관련 ID/검증: 권한 판정은 서버가 계속 매 요청 검사한다. 버튼 표시만 바뀌고, 관리자 셸은 들어갈 때 다시 확인한다. 입력은 기존 저장소·서버 검증을 쓴다.
- 접근성 대상/검증: 링크 대비, 본문 바로가기(6.4.1), 메모 제목 버튼 이름.
- 사용자 요청으로 이미 허용된 작업과 추가 확인이 필요한 작업: 수정·커밋·작업 브랜치 푸시 허용.

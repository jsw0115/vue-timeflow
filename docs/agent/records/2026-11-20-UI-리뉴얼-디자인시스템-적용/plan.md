## 1단계 진단 결과(2026-11-20 소스·브라우저 대조)

- 화면: 라우터 83개 경로 + 환경설정 섹션 약 15개. 사용자 화면 그룹 메인·플래너·기록·인사이트·소셜·환경설정, 별도 창 관리자(`AdminApp.vue`).
- 스타일 구조: `design-system/tokens.css`(토큰), `styles.css`(913줄, 대부분 한 줄에 여러 규칙, 전역 클래스), `interaction.css`, `typography.css`, `design-system/components.css`(공통 클래스 별칭), 화면별 scoped style. 아이콘 라이브러리 없음(유니코드 글자 아이콘). 로고 파일 없음(사이드바 `t` 글자 상자 + "timebar").
- 토큰 차이: 새 계약은 캔버스 `#FAF9F6`·카드 `#FFFFFF`·본문 `--color-body`·조작 경계 `--color-control-border`·`--color-accent-hover`·상태 성공색을 추가하고, 주 버튼을 검정 pill에서 accent 10px로, 카드 그림자를 없애고, 모서리를 4/8/10/14/18로 바꾼다. 코드의 `background: var(--color-canvas)` 94곳은 카드·입력·팝오버 배경이라 `--color-card`로 옮겨야 한다.
- 브라우저에서 본 문제(바꾸기 전 캡처 `scratchpad/pw/before/`)
  1. 위 여백 96px + 헤더 아래 96px로 첫 콘텐츠가 화면 아래쪽(약 265px)에서 시작한다.
  2. 페이지 제목이 화면 이름이 아니라 문구("오늘의 리듬을 시작해요")이고 JetBrains Mono다. 위에 영문 대문자 eyebrow("TIMEBAR WORKSPACE", "TODAY'S PLAN")가 반복된다.
  3. 로그아웃 상태에도 사이드바에 시연 계정 "Jisoo Kim·지수의 하루"가 보인다(신뢰 원칙 위반).
  4. 메뉴 아이콘이 서로 다른 모양의 유니코드 글자다.
  5. 플래너 시간축의 계획 블록이 점선이 아니라 진한 녹색 채움이고 글자 대비가 낮다(Plan/Actual 규칙 위반).
  6. 거의 모든 영역이 그림자 있는 카드다(card soup). 홈 히어로 안에 또 카드가 있다.
  7. 모바일에서 "새 글 작성"이 제목 아래 한 줄을 차지하고 그 아래 큰 공백이 남는다.
  8. 테마 설정이 고르는 즉시 적용되고 브라우저에만 저장된다. 미리보기·적용·취소·기본값 복원이 없다. 서버에는 계정별 설정 경로(`/api/settings/{section}`, `appearance`)가 있지만 화면이 쓰지 않는다.
- 우선순위: P0 토큰·공통 컴포넌트·앱 셸(모든 화면에 한 번에 반영) → P1 홈·일간 플래너·테마 설정 → P2 캘린더·일정·할 일·루틴·다이어리 → P3 인사이트·소셜·채팅 → P4 나머지 설정·관리자·서브 화면 → 전체 반응형·접근성 점검.

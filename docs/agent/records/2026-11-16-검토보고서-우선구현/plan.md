# 작업 계획

- 요청. `docs/output`의 검토보고서·근거집을 현재 소스와 대조하고 긴급도 순으로 구현 가능한 부분을 검증·커밋한다.
- 개발 방향. 첫 고객은 기존 경험이 있는 직무 전환자·재직자, 목표 흐름은 근거 선택 → 문서 한 부분 개선 → 행동 승인 → 결과물 연결이다. 이번 작업은 이 흐름의 신뢰성 기반을 보완하며 유료 출시를 선언하지 않는다.
- 현재 사실. 11월 15일 실제 기록·백업·캘린더 상태가 구현되어 10월 기준 보고서와 차이가 있다. AI·결제 화면의 고정 결과, 플래너 덮어쓰기, Nginx 10m와 서버 요청 11MB 불일치는 남아 있다.

## 순서와 검수

| 순서 | 적용 범위 | 검수 기준 |
| --- | --- | --- |
| P0-1 | AI·구독 화면의 서버 capability 조회, 시연 성공 제거, REQ-F18→WBS-02 연결 | 미연결·조회 실패·응답 누락·계정 전환 때 결과/결제 성공 표시 없음. 화면 테스트와 빌드 통과 |
| P0-2 | 기존 플래너의 version 필수 변경 계약과 낙관적 잠금 | 오래된 수정·상태 변경·삭제 409, 타 계정 404, 누락/음수 400, 동시 쓰기 한 건만 성공. 새 migration과 계약 검증 |
| P0-2 보완 | 파일 10 MiB·요청/프록시 11 MiB 정렬 | 설정 대조 및 실제 가능한 로컬 검사. 운영 업로드 검증과 구분 |
| P0-3 | 잔여 작업의 의존성·담당 역할·판정 시점 기록 | 실제 인력·예산·납기를 임의로 채우지 않고 미확정 조건 표시 |
| P1 | 한 고객군 4주 가치 실험 → AI·결제 베타 검수 → 실결제 관찰 | 외부 계약·검토자·허용 자료·원가·운영 검증 확보 후 착수 |
| P2 | 연구·기관·소셜·네이티브 확장 | 첫 흐름의 반복 사용·경제성 근거 이후 별도 판단 |

- 이번에 완료하지 않는 범위. 전 화면 서버 연결, 로컬 자료의 자동 이전, 동일 시간만으로 기록 자동 병합, AI/결제 제공자 연결, 실제 사용자 모집, 운영 DB 적용·배포·푸시. 동일 활동 식별과 이전은 원본·소유권·멱등성 계약부터 정리한다.
- 관련 보안. SC-04·18·19·34·36~38·44, 웹 IA·IN·PV·FU·XS, OWASP A01·A06·A08·A10. 서버 권한·버전·트랜잭션 검사와 Vue 텍스트 바인딩을 확인한다.
- 접근성. KWCAG 5.4.1, 6.1.1~2, 6.4.2, 7.3.1, 8.2.1의 상태 안내·재시도 버튼·키보드·작은 화면을 검수한다.
- 허용 범위. 사용자 요청은 로컬 구현·테스트·자체 변경 커밋까지 포함한다. 외부 제공자 계약·사업 책임자/예산 확정·운영 반영은 별도 후속 결정이다.

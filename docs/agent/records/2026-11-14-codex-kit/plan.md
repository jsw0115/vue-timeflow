# Codex 개발 지침 적용 계획

- 요청. 제공된 `Codex_바이브코딩_전용.zip`을 현재 Timebar Diary 프로젝트에 적용한다.
- 범위. 기존 AGENTS 규칙을 보존하며 프로젝트 맥락, 작업별 스킬, 보안·접근성 참고 문서, 작업 기록 양식과 보조 스크립트를 병합한다.
- 기준. 압축파일은 참고 자료이며 현재 사용자 지침과 실제 저장소 사실을 우선한다. 기능 코드, 운영 설정, 기존 사용자 변경은 이번 변경에 포함하지 않는다.

## 단계와 성공 기준

1. 압축파일과 실제 빌드·인증·DB·테스트 설정을 확인한다. 문서에는 확인된 값과 원본 경로만 기록한다.
2. 기존 문서로 연결하는 프로젝트 가이드와 스킬을 적용한다. DESIGN.md를 교체하거나 별도 디자인 권위를 만들지 않는다.
3. 작업 기록 생성·구조 검사 스크립트를 검토하고 적용한다. 원본과 기존 기록 보존, 잘못된 입력 거부를 시험한다.
4. 스킬 메타데이터, 49·28·33 목록, 로컬 문서 연결, 스크립트 동작을 검증하고 결과를 남긴다. 애플리케이션 보안 인증으로 표현하지 않는다.
5. 자체 변경만 검토하고 의미 단위 커밋한다. 환경이 Git 쓰기를 허용하지 않으면 그 제한과 미커밋 상태를 기록한다.

## 재개

`checklist.md`, `context-notes.md`, `verification.md` 순서로 확인하고 미완료 항목부터 이어간다. 현재 세션에는 토큰 충전 감지 또는 자동 재개 예약 도구가 없다.

# 작업 계획

- 요청: 남은 항목 점검에서 찾은 버그(BUG-015·BUG-016)를 고치고, 개선 항목(IMP-023~IMP-025)은 질문으로 모아 정리한다.
- 현재 확인한 사실: `session.js`의 `refresh()`는 갱신 실패 때 `clearSession()`만 한다. 탭 제목은 `index.html`의 `<title>` 하나다. 앱 셸은 화면 이름(`pageName`)을 이미 계산한다.
- 범위/제외: 서버·API는 바꾸지 않는다. IMP-023~IMP-025는 고치지 않고 질문으로 정리한다. 수정 중 다시 멈춘 device-preview 시험의 원인을 찾아 시험만 고친다(BUG-017).
- 성공 기준: 서버가 세션을 끝내면 안내가 보이고 다시 로그인하면 사라진다. 직접 로그아웃은 안내 없음. 106개 경로의 탭 제목이 화면 이름을 가진다. 전체 시험이 제한 시간 안에 통과한다.
- 보안 관련 ID/검증: 세션을 지우는 조건은 그대로이고 안내만 더한다.
- 접근성 대상/검증: 6.4.2 제목 제공, 안내의 `role="alert"`.
- 사용자 요청으로 이미 허용된 작업과 추가 확인이 필요한 작업: 수정·커밋·작업 브랜치 푸시 허용. IMP-023~IMP-025는 사용자 결정 필요.

# 맥락 메모

## 결정

- 행동 버튼: 사용자 규칙("주 버튼이 있으면 행동 버튼은 넣지 않음")을 그대로 따랐다. 모든 사용자 화면에 헤더 주 버튼이 있어 행동 버튼을 하나도 넣지 않았고, 다음 행동은 화면에 있는 실제 버튼·필터 이름("+ 새 루틴", "+ 친구 찾기", "다른 상태")으로 문구에 적었다.
- 공유 그룹 카드의 "아직 멤버가 없어요"는 멤버 칩 줄 안의 인라인 글자라 블록 여백을 주면 줄이 깨진다. 문구만 고치고 `form-note`로 두었다.
- 상태 색: 같은 hex라도 카테고리·템플릿·시간 블록·단계 배지처럼 사용자가 고르거나 범주를 나타내는 색은 콘텐츠 색이라 바꾸지 않았다. 테마가 상태 색을 바꿀 때 사용자 카테고리 색까지 바뀌지 않게 하려는 구분이다. 소셜 로그인의 아이콘 대용 글자 색도 장식이라 두었고, 같은 화면의 "연동 해제"는 파괴적 동작이라 danger 변수로 바꿨다.
- 컴포넌트 전환은 마크업을 바꾸지 않고 기존 클래스를 공통 컴포넌트의 별칭으로 묶었다. 탭 47곳은 선택 표시가 모두 `.selected`라 CSS만으로 같은 규칙을 줄 수 있고, 마크업을 바꾸면 화면마다 다른 상태 연결을 건드려야 한다. 기존 정의는 지우고 `components.css` 한 곳에서 관리한다.
- `.modal-secondary`는 정의가 사용자 미커밋 `Modal.vue`에 있다. 그 파일을 고치면 사용자 변경과 섞여 커밋을 나눌 수 없어 건드리지 않고, `button.modal-secondary`로 우선순위를 높여 공통 규칙이 이기게 했다. 사용자가 `Modal.vue`를 정리할 때 그 안의 `.modal-secondary` 규칙은 지워도 된다.
- 입력 필드: 폼 구조가 화면마다 달라 `.input-field` 마크업으로 바꾸지 않고, 테두리가 있는 기존 입력에 hover(muted 테두리)·disabled(0.45) 공통 상태만 줬다.
- 색상 테마: 기존 두 축(표면·포인트)을 유지하고, 포인트를 고르면 데이터·상태 색까지 표면에 맞춰 계산하게 했다. 밝기만 옮기는 방식이라 고른 색의 색상은 유지된다. accent 하한을 7:1로 둔 이유는 링크·강조 글자로도 쓰이고 데이터 색이 그보다 한 단계 약해 보일 여유가 필요해서다. 프리셋 5종은 이 기준을 원래 넘는다.
- 기본(라이트·포레스트)은 DESIGN.md 값과 정확히 같아야 해서 프리셋 데이터 색을 상수로 두었다(계산식으로는 #4d7963이 나와 한 자리 다름).
- 사용자 지정 색이 기준에 못 미치면 바꾼 값과 방향을 설정 화면에 알린다. 조용히 바꾸면 고른 색과 화면 색이 달라 혼란스럽다.

## 발견

- 320~360px에서 앱 셸 전체가 가로로 넘친다. 이번 변경 전 스타일로 되돌려도, 손대지 않은 자동화 설정 화면에서도 같아 기존 문제다(IM-11 발견에 기록).
- 다크 테마에서 포인트 컬러가 포커스 기준에 못 미쳤고(2.46:1) 상태 색 3종도 미달이었다. 색상 테마 계산으로 해소했다.
- 테마 설정 화면에서 `.setting-content input` 공통 규칙과 `.form-note`의 `inline-flex`가 새 요소 배치를 깨뜨렸다. 화면 전용 스타일로 막았다.

## 보안 점검

- 사용자 지정 색은 `isHex`(`#rrggbb`)를 통과한 값만 저장·적용한다. localStorage에서 읽을 때도 검사하고, 아니면 기본 색을 쓴다. CSS 변수에 임의 문자열이 들어가지 않는다.
- 새 외부 자원·네트워크 요청 없음.

## 접근성 점검

- 아이콘만 있는 버튼 9곳에 `aria-label`. 알림 버튼은 안 읽은 개수를 이름에 포함한다.
- 검색·필터로 비는 빈 상태에 `role="status"`.
- 색상 테마 칩·표면 카드에 `aria-pressed`, 색 선택 입력은 라벨("직접 고르기")로 이름을 받는다. 현재 대비 값 안내는 `role="status"`.
- 미리보기 영역은 `aria-hidden`이라 안의 버튼·체크에 `tabindex="-1"`을 줘 탭 순서에서 뺐다(기존에는 숨겨진 버튼에 포커스가 갈 수 있었다).
- 대비: 모든 표면 × 색 조합을 자동 검사한다. 320px·키보드·화면낭독기 실측은 NOT_RUN.

# 작업 계획

- 요청(2026-11-18): ① 빈 목록 문구 47곳을 empty-state로 통일, 문구는 "무엇이 비었는지 + 다음 행동", 화면에 주 버튼이 있으면 행동 버튼은 넣지 않음 ② 나머지 항목(상태 색 변수, 탭·아이콘 버튼·보조 버튼·입력 필드 전환)도 자연스럽게 변경 ③ 환경설정 > 테마·디자인에서 여러 색상 테마로 사용자 지정 설정.
- 현재 확인한 사실
  - 47곳 중 4곳은 빈 목록이 아닌 규칙 안내 문구다. 기존 `.empty-state` 2곳을 더해 대상은 45곳(블록 44, 인라인 1).
  - 모든 사용자 화면은 헤더에 주 버튼 "＋ 새 글 작성"이 있다. 관리자 화면의 빈 상태는 상태·필터 결과다.
  - 상태 색 hex 41곳 중 21곳이 상태 표시, 20곳은 같은 값의 콘텐츠 색이다.
  - 탭·필터·작성 탭은 모두 `.selected` 클래스로 선택을 표시한다. `.modal-secondary` 정의는 사용자 미커밋 파일 `Modal.vue`에 있다.
  - 테마는 표면 4종 × 포인트 5종이 이미 있지만 데이터·상태 색은 테마를 따르지 않고, 다크에서 포인트 컬러 대비가 2.46:1이다.
- 범위: 위 세 요청. 커밋은 빈 목록 / 상태 색 / 컴포넌트 / 색상 테마 / 문서로 나눈다.
- 제외: `Modal.vue` 수정, nav-item 모서리·`.primary` 글자 크기(4단계 나머지), 표면 질감(3단계), 320px 가로 넘침(기존 문제).
- 성공 기준: 빈 목록 검사·토큰 검사·색 테마 대비 검사 통과, 프런트 전체 테스트·빌드 통과, 바뀐 화면 캡처 확인.
- 보안: 사용자 지정 색은 `#rrggbb` 형식만 저장·적용(그 외는 기본 색). localStorage 값 검증 유지.
- 접근성: 아이콘 버튼 이름, 검색·필터 빈 결과 `role="status"`, 색 대비 자동 보장, 색 선택 입력 라벨, 미리보기 안 요소 탭 순서 제외.
- 허용된 작업: 코드·문서 수정과 로컬 커밋. 푸시는 하지 않는다.

# 작업 계획

- 요청: 남은 항목을 모두 진행한다(사용자 요청 "남은 항목들 전부 다 진행해줘").
- 현재 확인한 사실: [추가 점검](../../../quality/browser-test-2026-11-27.md)의 "확인하지 못한 것"과 IMP-021의 남은 위험(역할 확인 실패 시 새로고침 전까지 재확인 없음).
- 범위/제외: 관리자 버튼 재확인을 고치고, 실제 글꼴·사용자 지정 색·시스템 설정·실제 백엔드 다중 계정 흐름·로그인 제한·관리자 화면을 점검한다. 화면 읽기 프로그램·실기기는 이 환경에 없어 접근성 구조 읽기·기기 에뮬레이션으로 대신하고 그렇게 표시한다. 새로 찾은 항목은 기록만 한다.
- 성공 기준: 각 항목의 결과와 근거를 결과서·원장·07 RUN에 남긴다. 대신한 점검은 대신했다고 적는다.
- 보안 관련 ID/검증: 관리자 권한 검사는 서버 그대로. 관리자 역할 변경은 격리 DB에서만.
- 접근성 대상/검증: 페이지 제목·랜드마크·h1·터치 대상. 정식 점검 아님.
- 사용자 요청으로 이미 허용된 작업과 추가 확인이 필요한 작업: 수정·커밋·작업 브랜치 푸시 허용. 새 항목(BUG-015·BUG-016·IMP-023~IMP-025) 처리는 사용자 결정 필요.

## 표기 기준

- **API**: 백엔드 Controller의 경로 접두다. 세부 경로·필드는 API 명세에서 확인한다.
- **서버**: `구현`(처리·저장 코드 있음), `일부`, `미연결`(503 경계), `없음`.
- **화면**: `서버`(화면이 서버 API를 호출), `로컬`(브라우저 저장·시연), `일부`, `상태 표시`(미연결 상태만 표시).
- **검증**: 최근 실행 증빙이 있는 자동 테스트. 실행 기록은 [07 결과서](07-테스트-시나리오-및-결과서.md)에 남긴다.
- 화면 열은 2026-11-17에 `frontend/src`에서 서버 호출 모듈(`features/auth`, `features/chat`, `features/recording`, `features/backup`, `features/integrations`)을 쓰는 화면을 찾아 정한 값이다(정적 확인).

## 서비스 목적

Timebar Diary(저장소 `vue-timeflow`)는 **계획(Plan)과 실제 기록(Actual)을 같은 시간축에서 비교**하는 개인 시간관리 서비스다. 일정·할 일·루틴·다이어리·메모·업무·경력·채팅을 하나의 계정 안에서 연결해, 흩어진 계획과 기록을 다음 행동과 문서로 이어 주는 것을 목표로 한다.

2026-11-20부터 이 기반 위에 업무·학습·프로젝트 활동을 경력·지원 문서·포트폴리오로 이어 가는 통합 커리어 관리 서비스로 확장 중이다. 제품 방향은 [Career OS 통합 개편안 v2.0](../Career_OS_통합_개편안_v2.0.md)과 [docs/design](../design/README.md) v2.1(제안·결정 대기 포함)이고, 지금 소스에 들어간 것은 1단계(커리어 묶음, 활동 타임라인, 취업·이직 지원, 커리어 목표)다. 범위와 미착수 항목은 [소스 대조 기록](../design/14-baseline-reconciliation.md)을 본다.

사용자가 이 서비스로 하려는 일은 네 가지다(DESIGN.md 1장).

1. 오늘의 일정과 할 일을 빠르게 파악한다.
2. 계획한 시간과 실제로 사용한 시간을 비교한다.
3. 작성 흐름을 끊지 않고 일정·할 일·루틴·다이어리 기록을 남긴다.
4. 지난 기록과 통계를 부담 없이 되돌아본다.

웹·API 선언 버전은 0.1.0이다. 운영 배포·매출·릴리스 태그는 확인된 상태가 아니며, 화면이 있다는 이유로 서버 저장이나 외부 연동이 끝났다고 보지 않는다.

## 핵심 개념

| 개념 | 설명 |
| --- | --- |
| 계획(Plan) | 일정·할 일처럼 미리 정한 시간. 타임라인에서 점선으로 그린다 |
| 실제 기록(Actual) | 실제로 쓴 시간. '지금부터 기록'·집중 타이머로 남기며 실선과 시간으로 그린다 |
| 기록 연결 | 일정·할 일에서 바로 실제 기록을 시작하고, 상세 화면에서 서로 연결된 기록을 본다 |
| 하루 모드 | J형(계획형)·P형(즉흥형)·밸런스형. 홈 문구·작성 항목·통계 포틀릿 기본값이 모드를 따른다. 사이드바 위에서 바꾸며 이 브라우저에 저장된다 |
| 하루의 기준 | 하루 시작 시각(0~6시)과 계정 시간대. 로그인 상태에서 계정에 저장하고 플래너·통계 날짜 계산에 쓴다 |
| 커리어 목표 | 취업 준비·이직 준비·재직 중 성장·프로젝트 참여. 커리어 대시보드의 영역 순서만 바꾸고 공개 범위·권한은 바꾸지 않는다. 온보딩·환경 설정·커리어 대시보드에서 고르며 로그인 상태면 계정, 로그아웃이면 이 브라우저에 저장한다 |
| 커리어 활동·지원 기록 | 활동(업무·학습·프로젝트 등)과 취업·이직 지원을 나만 보기로 계정에 남긴다. 링크는 http/https만 저장하고 서버가 호출하지 않는다. 로그아웃 상태에서는 저장하지 않는다 |
| 계정 저장과 로컬 저장 | 로그인하면 계정(서버)에 저장하는 화면이 있고, 로그아웃이면 "이 브라우저에만 저장돼요"를 보이고 브라우저에 저장한다 |

## 저장 방식 표기

[04 메뉴기능 목록서](04-메뉴기능-목록서.md#저장-방식-표기)와 같은 표기를 쓴다.

| 값 | 의미 |
| --- | --- |
| 서버 | 서버 API로 계정별 저장·조회한다. 로그아웃이면 로그인 안내를 보이는 화면이 많다 |
| 서버·로컬 | 로그인하면 계정(서버), 로그아웃이면 이 브라우저에 저장하고 그 사실을 화면에 보인다 |
| 일부 | 화면의 일부 기능만 서버를 부른다 |
| 로컬 | 브라우저 저장·시연 데이터 중심이다. 계정 저장이 끝난 화면으로 소개하지 않는다 |
| 시연 | 고정된 예시 값이다. 새로고침하면 처음으로 돌아가고 서버에 저장하지 않는다 |
| 상태 표시 | 외부 제공자가 연결되지 않은 상태를 서버에서 조회해 보이기만 한다 |
| 저장 없음 | 계산만 하고 저장하지 않는다 |

## 화면 공통 기능

| 기능 | 위치 | 설명 | 저장 |
| --- | --- | --- | --- |
| 페이지 헤더 | 모든 앱 화면 위 | 현재 위치(메뉴 묶음)·화면 이름·설명, 화면의 대표 행동 버튼(예: '+ 새 할 일') | 해당 없음 |

| 알림 패널 | 헤더 알림 버튼 | 안 읽은 알림 수, 알림 목록 | 로컬 |
| 멘션 바로가기 | 헤더 @ 버튼 | 멘션함으로 이동, 안 읽은 멘션 표시 | 서버 |

| 하루 모드 전환 | 사이드바 위 | J형·P형·밸런스형 전환 | 로컬 |
| 계정 영역 | 사이드바 아래 | 로그인하면 계정 이름·이메일과 프로필 이동, 로그아웃이면 로그인 안내 | 해당 없음 |
| 떠 있는 대화 버튼 | 화면 오른쪽 아래 | 채팅 창 열기·위치 옮기기 | 서버(로그아웃이면 시연) |
| 전송 대기 | 앱 화면 위 | 연결이 끊긴 동안 만든 메모·할 일 변경 건수, 확인이 필요한 변경 비교·삭제 | 이 기기 보관 후 서버 |
| 관리자 콘솔 | 사이드바 아래 | 관리자 화면을 별도 창으로 연다. 서버가 관리자로 확인한 계정에만 버튼이 보인다(권한은 매 요청 서버가 확인) | 해당 없음 |

## 관리자 메뉴 기능 목록

### 접근 방식

- 사용자 화면 사이드바의 '관리자 콘솔'을 누르면 별도 창(`AdminApp`)이 열린다. 이 창에는 사용자 메뉴가 없고 관리자 메뉴만 있다. '관리자 콘솔' 버튼은 `/api/admin/stats`로 서버가 관리자로 확인한 계정에만 보인다. 버튼을 숨기는 것은 보안 통제가 아니다.
- 창을 열 때 서버가 현재 계정의 상태(ACTIVE)와 역할(ADMIN)을 확인한다. 일반 계정·로그아웃 상태에는 권한 없음 또는 로그인 안내만 보인다. 서버 API(`/api/admin/**`)도 ADMIN 역할만 허용한다.
- 관리자 역할을 주는 화면은 없다. 로컬 점검용 관리자 계정은 격리 DB에서 역할을 바꿔 만든다([07 테스트 결과서](07-테스트-시나리오-및-결과서.md) PR-10 5단계 사전 조건).

## 연결되지 않은 외부 기능

아래 기능은 화면·설정값이 있어도 실제 제공자와 연결되어 있지 않다. 서버의 실행 요청은 503 경계를 돌려준다([연계 명세](../api/frontend-backend-2026-10-10/integrations.md)).

| 기능 | 화면 | 현재 동작 |
| --- | --- | --- |
| AI 분석·작성 | AI 리포트, 자동화·AI | 미연결 상태 표시 |
| 결제·구독 | 구독·멤버십, 구독/결제 관리 | 미연결 상태 표시·시연 |
| 외부 캘린더 동기화 | 동기화, 연동 설정 | 미연결 상태 표시 |
| 소셜 로그인 | 로그인, 소셜 로그인 연동 | 미연결 안내 |
| 메일·알림톡 발송 | 비밀번호 재설정, 알림 설정, 갓생 리포트 메일 | 발송하지 않음(알림톡 인증은 시연 문구로 안내) |

## 현재 한계

- 저장 방식이 '로컬'·'시연'인 화면은 계정을 바꾸거나 다른 기기에서 열면 같은 데이터를 볼 수 없다. 서버 연결 순서는 [01 개발 우선순위](01-개발-우선순위.md)와 [09 잔여 개발 항목 기획서](09-잔여-개발-항목-기획서.md)를 따른다.
- 주간·월간·연간 플래너, 일간·카테고리 통계, 비교 분석, 업무 리포트·히스토리, 홈 일부 위젯은 예시 값이다. 화면에 '시연용 예시 데이터'를 표시한 화면과 표시가 없는 화면이 섞여 있다.
- 관리 화면 중 구독/결제 관리는 시연, 전체 화면은 이 브라우저 저장이고, 나머지는 서버에 연결됐다(관리자 설정은 읽기 전용).
- 커리어 화면에서 활동의 근거 원본 연결, 문서 버전과 지원별 제출본, 포트폴리오 공개 링크는 서버에 연결됐다. 프로젝트 허브, GitHub·클라우드·AI 연동은 결정 대기 또는 미착수다. 공고를 자동으로 가져오거나 대신 지원하지 않으며, 저장한 링크를 서버가 호출하지 않는다.
- 모바일 앱(Capacitor)·데스크톱 앱(Electron)은 구성만 있고 서명·스토어 검수는 별도다.
- 영어를 골라도 약관 본문, 시연 예시(사람 이름·예시 글·예시 알림 제목), 전체 화면 목록의 화면 이름·설명은 한국어다. 다른 언어(일본어·중국어)는 필요할 때 추가한다(09 Q-38).

## 작성 기준

- **근거 문서**: [요구사항](../planning/requirements.md)(REQ), [기능 명세](../handbook/source/05-기능-명세서.md), [테스트 계획](../quality/test-plan.md)(TC), [구매자 의견](../product/customer-feedback-2026-11-14/README.md)(CF), 이 폴더의 01~07 문서다. 요청에서 언급한 `docs/reference` 폴더는 저장소에 없어 사용하지 않았다(2026-11-18 확인).
- **소스 대조**: 입력 규칙과 상태 코드는 2026-11-18 기준 소스에서 확인한 값이다. 화면 검증은 `frontend/src/utils/postValidation.mjs`·`recurrence.mjs`, 서버 검증은 `feature/FeatureInput.java`·`FeatureType.java`, `auth/PasswordPolicy.java`, `common/ErrorCode.java`, `records/ActualRecordingService.java`, `operations/BackupService.java`, `task/checklist/TaskChecklistService.java`를 따른다. 소스와 이 문서가 다르면 소스를 따르고 이 문서를 고친다.
- **사용자 정의의 한계**: 아래 사용자 유형은 구매자 의견(CF-001, CF-004 등)에서 끌어낸 가정이다. CF 원문은 가상의 익명 의견이며, 실제 인터뷰 결과가 아니다.
- **ID**: 사용자 기능은 `UF-번호`, 테스트 케이스는 `UT-번호`다. 한 번 쓴 번호는 삭제 후 재사용하지 않는다.
- **결과 표기**: 이 문서는 테스트를 정의만 한다. 모든 UT의 실행 결과는 NOT_RUN에서 시작하며, 실행하면 07 문서에 RUN 행을 추가하고 이 문서의 "최근 결과"를 갱신한다.

## 공통 요구

모든 서버 연결 기능에 적용한다. 각 기능의 테스트 케이스에 다시 적지 않는다.

| ID | 요구 | 기준 | 테스트 |
| --- | --- | --- | --- |
| UF-C1 | 내 기록만 보인다 | 사용자는 JWT로 정한다. 본문에 다른 owner를 넣어도 무시하거나 거절한다. 다른 계정의 기록은 404다 | UT-C1 |
| UF-C2 | 남이 먼저 고친 내용을 덮어쓰지 않는다 | 수정·삭제는 조회한 version을 보낸다. 오래된 version은 409이고, 화면은 입력을 보존한 채 다시 조회하도록 안내한다 | UT-C2 |
| UF-C3 | 오류 원인을 구분해서 안내받는다 | 400 입력 오류, 401 인증 만료, 403 권한 없음, 404 없음, 409 충돌, 503 외부 제공자 미연결. 응답은 `success`·`data`·`message` 구조다 | UT-C3 |
| UF-C4 | 저장에 실패해도 쓰던 내용이 사라지지 않는다 | 실패 응답이나 통신 끊김에서 입력값을 화면에 남기고 다시 시도할 수 있다 | UT-C4 |
| UF-C5 | 시연 화면과 실제 저장을 헷갈리지 않는다 | 로컬 저장 화면을 서버 저장 완료로 표시하지 않는다. 미연결 기능은 "준비 중" 상태로 보이고 실행되지 않는다 | UT-C5 |
| UF-C6 | 글자 수 제한을 미리 안다 | 서버 공통 한도는 일반 문자열 200자, `body`·`handover` 20,000자, 배열 500개다. 화면은 같은 한도를 안내한다 | UT-C6 |
| UF-C7 | 키보드·작은 화면에서도 쓴다 | 320px 폭, 200% 확대, 키보드 이동, 포커스 표시, 동작 줄이기 설정을 지원한다 | UT-C7 |
| UF-C8 | 미완료를 실패처럼 보지 않는다 | 화면 문구에 "실패"를 쓰지 않고 "이월", "다음에"를 쓴다(DESIGN.md 6장) | UT-C8 |

## 테스트 케이스

### 작성 규칙

- **유형**: 정상(N), 경계(B), 입력 오류(E), 권한(A), 충돌(C), 복구(R).
- **층**: 서비스·HTTP(MockMvc)·Node(프런트 단위)·브라우저. 한 층에서 통과해도 다른 층의 검증을 대신하지 않는다.
- **계정**: 테스트 계정 A·B·ADMIN을 쓴다. 운영 데이터를 쓰지 않는다.
- **기존 테스트**: "관련 테스트"는 같은 기능을 다루는 기존 클래스다. 그 클래스가 해당 케이스를 정확히 검사하는지는 구현할 때 확인한다.

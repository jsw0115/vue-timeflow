# 다국어 용어 목록

문서 버전 v1.0. 작성일 2026-11-25. 수정일 2026-11-25. 화면 영어 번역(PR-32)에서 여러 화면에 반복해 쓰는 제품 용어의 한국어·영어 짝을 적는다. 09 Q-38 (4) 결정에 따라 용어는 코드 사전([`frontend/src/features/i18n/dictionary.mjs`](../../frontend/src/features/i18n/dictionary.mjs))과 시험으로 관리하고, 이 문서로 일관성을 점검한다.

## 쓰는 규칙

- 한국어가 원문이다. 사전의 키는 화면에 보이는 한국어 원문 그대로이고, 영어가 없으면 한국어를 보인다.
- 아래 표의 영어는 사전 값과 같아야 한다. `frontend/tests/i18n-dictionary.test.mjs`가 이 표를 읽어 사전과 다르면 실패한다. 용어를 바꿀 때는 사전과 이 표를 함께 고친다.
- DESIGN.md 7장 "Voice and microcopy"의 기존 용어 매핑(Plan=계획, Actual=실제 기록, Event=일정, Task=할 일, Routine=루틴, Diary=다이어리)을 따른다.
- 같은 한국어를 화면마다 다른 뜻으로 쓰면 사전 키 하나에 영어가 하나뿐이라 뜻이 섞인다. 이때는 한국어 이름표를 나눈다(예: 반복 설정의 "종료"는 "종료 조건", 버전 비교의 "추가"는 "추가됨").
- 사용자가 쓴 기록·예시 자료 제목은 옮기지 않는다. 분류·상태처럼 저장값이 한국어인 목록은 저장값을 그대로 두고 화면 글자만 옮긴다.

# 설계 문서 검증 기록

> 아래는 2026-09-26 당시 기록이다. 2026-09-27 추가된 채팅 15개를 포함한 현행 104개 API와 문서 누락 대조는 [최신 점검 결과](../api/api-audit-2026-09-27.md), 실행·UI 검증은 [채팅 기록](../chat/verification/README.md)을 참고한다.

2026-09-26 · 대상: `docs/design/`, `docs/api-info/`, 문서 생성·검사 스크립트.

## 1차 · 소스와 설계의 추적성

- Java 컨트롤러 89개를 별도 현행 계약으로 추출: 서비스 연결32 / 계약 stub52 / 공용 메모리 플래너5. 서비스 연결은 실제 운영 검증 완료를 뜻하지 않습니다.
- 기존 목표 API 114개 ID의 포함 여부를 검사하고 55개를 추가하여 총169개로 정리했습니다.
- V1의37개 CREATE 테이블에서 컬럼·타입·NULL·기본값·PK·인덱스·FK를 추출했습니다. DB introspection 결과는 아닙니다.
- DDL의 `tbl_*` 이름, 접두사 없는 FK 참조 및 JPA 매핑의 불일치와 `CREATE OR REPLACE` 재실행 위험을 별도 기록했습니다.
- 이번 변경은 문서와 문서 생성·검사 스크립트만 대상으로 합니다. 애플리케이션 기능 구현, SQL 수정/실행, 데이터 변경은 하지 않았습니다.

## 2차 · 보안·도메인 계약 검토

- 브라우저/네이티브 토큰 계약 분리, CSRF 쿠키 경로와 서명, 리소스 소유·멤버·관리자 권한, OAuth state/PKCE·redirect allowlist를 명시했습니다.
- 동시 수정의 ETag/If-Match, upsert 조건 헤더, POST 멱등키, 204 무본문, 202 작업 상태 조회를 정리했습니다.
- 업무 유형별 필수 입력, 일정 종료>시작, 시간대, 종일 일정, 날짜 범위, 태그·멘션의 접근 제약을 계약에 포함했습니다.
- 비동기 파일 업로드 후 상태 조회와 캘린더 전용 OAuth 시작 경로를 보완했습니다. 커뮤니티/그룹 초대 응답은 실제 가입 완료와 구별했습니다.
- 개인정보·토큰을 오류/로그에 노출하지 않는 원칙, AI 전송 동의와 사용자 확정, 외부 실패의 제한된 재시도를 문서화했습니다. 보안 기능의 구현이나 침투 테스트를 완료했다는 뜻은 아닙니다.

## 3차 · 자동 정적 검증

프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
node frontend/scripts/design-docs/build.mjs . --check
node frontend/scripts/design-docs/check.mjs .
```

- 생성 결과 최신성 비교, 기존 API ID 누락/중복, 경로 파라미터 필수 정의 및 schema 참조 해소를 검사합니다.
- 요청·성공·오류 예시에 대해 사용자 정의 JSON Schema 부분집합 검사: type, required, enum, const, anyOf/oneOf/not, additionalProperties, 문자열/숫자/배열 제약과 일부 날짜 형식.
- 204 본문 금지, 예시 일정의 날짜 역전, 상태 변경 응답을 검사합니다.
- 신규 Markdown 파일의 로컬 링크 존재 및 코드 펜스 균형을 검사합니다. 링크 anchor의 렌더러별 동작은 별도입니다.
- 검증 중 메모·채팅의 anyOf 제약을 예시 생성기가 문자열로 잘못 처리하는 문제를 수정했습니다.

자동 검사 통과: 목표 API169개 / 현행 API89개 / DDL 테이블37개 / 파라미터·요청·응답 예시2,107개 / Markdown21개 / 로컬 링크257개. 생성 결과19개 산출물의 최신성도 별도 비교합니다. 이 숫자는 이번 문서 세트 기준이며 추가 시 증가할 수 있습니다. 검사기는 자체 구현한 부분집합이며 **OpenAPI 3.1 전체 적합성 인증 도구가 아닙니다.**

## 미수행 범위·구현 전 체크리스트

- 실제 MariaDB 스키마 조회, migration 적용/롤백/백업 복원, 데이터 손실 검증은 미수행입니다. 이름 정합화와 기존 DB 상태 확인이 선행되어야 합니다.
- HTTP 호출, JWT/CSRF/CORS 동작, IDOR·권한 우회, 동시 수정·멱등 race 및 부하 테스트는 미수행입니다.
- 웹·iOS·Android·데스크톱 화면 동작, Mermaid 도표의 시각 렌더링은 미수행입니다.
- 공식 OpenAPI validator 및 코드 생성기 호환성은 구현 CI에서 추가 검증해야 합니다.
- OAuth/메일/FCM/APNs/Google Calendar 실 계정·sandbox 연동, 키 회전, 장애 복구는 미수행입니다.
- SMS/카카오 알림톡·AI·객체 스토리지 사업자는 아직 미선정입니다. 공급자별 계약/비용/동의/보존 정책을 확정하기 전 운영 연결하지 않습니다.
- API의 보존 기간·쿼터·성능 목표는 제안값입니다. DB migration, 보안 정책, 화면과 최종 합의한 뒤 구현 acceptance test로 고정하세요.

참고: 사용자 제공 블로그는 접근 가능한 제목 외 본문을 충분히 확인하지 못했고, 동영상 내용은 확인하지 못했습니다. 이를 근거로 세부 내용을 인용하지 않았으며 외부 통신 규격은 [인터페이스 문서](05-external-interfaces.md)에 연결한 공식 문서를 사용했습니다.

# 데모 사용자 화면 캡처 (2026-11-22)

실제 로그인 화면으로 데모 계정에 로그인한 뒤, 메뉴 순서대로 모든 화면을 1440px 폭으로 캡처했다. 본문 스크롤 영역까지 펼쳐 한 장에 담았다(최대 높이 7000px).

## 환경

- 격리 개발 환경만 사용: `infra/chat/compose.yml`(MySQL 8.4·Redis 7.4) + 백엔드 `chat-local` 프로필 + Vite 개발 서버. 운영 데이터와 무관하다.
- 브라우저 시계는 2026-11-22(일) 16:20 KST로 고정했다. 서버가 찍는 시각(채팅 메시지 시각 등)은 실제 실행 시각이다.
- 데모 계정(격리 DB에만 있음, 이메일은 `example.com`)
  - 김지원 `demo.jiwon@example.com` — 캡처 주인공(USER)
  - 박서연 `demo.seoyeon@example.com` — 친구·커뮤니티 운영자
  - 이민준 `demo.minjun@example.com` — 친구. 관리자 화면 캡처용으로 격리 DB에서 역할만 ADMIN으로 바꿨다

## 읽을 때 주의

- 화면에 "시연용 예시 데이터"라고 적힌 영역은 앱이 원래 로컬 예시를 보여 주는 곳이다. 서버 데이터가 아니다.
- 커뮤니티 목록·관리자 사용자 목록에는 같은 격리 DB에 이전 테스트가 남긴 합성 계정·커뮤니티(`@example.test` 등)가 함께 보인다.
- 일반 사용자의 `/sitemap`은 관리자 화면이라 관리자 계정(`106_95-관리자-시스템_전체-화면.png`)으로만 캡처했다.
- 파일 이름: `순번_메뉴묶음_화면이름.png`. `_index.tsv`는 파일 이름과 캡처한 주소의 대응표다(커뮤니티 하위 화면 070–078, 채팅방 066–067은 다시 찍어 주소가 표와 다를 수 있다).

# 프런트엔드 기준 API 구현 계획

현재 Vue 라우트·store·작성 흐름을 근거로 API 목록과 요청·응답·오류·권한 계약을 정하고, 기존 Java 17 / Spring Boot 백엔드를 기능별로 확장한다.

1. 화면과 로컬 데이터 구조를 서버 컨트롤러와 대조한다. 검증은 기능별 소스 경로와 endpoint 목록으로 한다.
2. 기존 `/api` 계약을 유지하면서 미구현 기능을 영속화하고, 누락 기능의 API를 추가한다. 개인 데이터는 인증 사용자로 격리하고 소셜은 회원 권한, 관리자는 ADMIN 권한을 검사한다.
3. DTO·검증·DB migration·서비스·HTTP 컨트롤러와 API 스펙을 작성한다. 외부 제공자가 필요한 기능은 실행 가능한 내부 처리와 제공자 의존 부분을 명확하게 구분한다.
4. 서비스·HTTP 계약·영속 저장 테스트와 프런트엔드 빌드를 실행하고 결과와 한계를 기록한다.

기존 사용자 변경인 `AGENTS.md`, `frontend/src/components/Modal.vue`, `.claude/settings.local.json`, `my-skill/`은 수정하거나 커밋하지 않는다. 실제 로컬 DB에 migration을 적용하거나 배포하는 작업은 포함하지 않는다. 이번 요청은 백엔드 소스와 명세 작성이며 프런트엔드 화면을 서버 호출로 전환하는 작업은 포함하지 않는다.

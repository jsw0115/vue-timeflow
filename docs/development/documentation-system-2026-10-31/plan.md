# 개발·기획·운영 문서 통합 계획

작성일 2026년 10월 31일. 수정일 2026년 10월 31일.

프로젝트의 기획·사업·설계·개발·검증·설치·운영·릴리스·포트폴리오 문서를 한국어 Markdown으로 완성하고, 중복 본문을 하나의 기준 문서로 통합합니다. 앱 기능 구현·실제 서버 배포·유료 서비스 개통은 포함하지 않습니다.

1. 실제 코드·설정·문서와 Git 이력을 대조해 현재 구현, 과거 기록, 향후 설계를 구분합니다.
2. 문서별 기준 위치와 중복 정리 방법을 정하고 기존에 검증한 설치·API·DB 자료를 재사용합니다.
3. 누락된 RFP·요구사항·사업 계획·WBS·용어·코드 규칙·모듈·테스트·운영·포트폴리오 문서를 작성합니다.
4. 릴리스와 날짜별 작업 원장을 연결하고 실제 배포 여부와 계획 버전을 명시합니다.
5. 링크·목차·요구사항 추적·DB/API 소스 일치·문서 중복을 검사하고 검증 결과를 기록한 뒤 커밋합니다.

도식은 Mermaid와 텍스트 와이어프레임을 우선 사용해 Markdown에서 유지보수합니다. 기존 Word 안내서는 Markdown 기준 원문에서 생성한 배포 산출물로 구분합니다.
